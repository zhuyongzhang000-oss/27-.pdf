# 习思想 第十章 建设社会主义文化强国

## 记忆部分

### 1. 文化繁荣兴盛 [p171]

（1）文化**繁荣兴盛**是：**①实现中华民族伟大复兴的精神支撑；②建设社会主义现代化强国的应有之义；③满足人民日益增长的美好生活需要的内在要求；④在世界文化激荡中站稳脚跟的前提基础**。

（2）建设社会主义文化强国、推动社会主义文化繁荣兴盛，**关键**在于**坚定中国特色社会主义文化自信**。

（3）文化自信的依据和来源：

| | |
|---|---|
| **深厚基础** | **中华优秀传统文化** |
| **坚强基石** | **党带领人民在伟大斗争中孕育的革命文化和社会主义先进文化** |
| **现实基础** | **中国特色社会主义伟大实践** |

（4）决定社会主义文化事业前途命运的关键是**坚持为人民服务、为社会主义服务的根本方向**。

### 2. 坚持党的文化领导权 [p171]

（1）我国的**根本文化制度**：坚持马克思主义在意识形态领域指导地位的根本制度。

（2）当代中国哲学社会科学区别于其他哲学社会科学的**根本标志**：**坚持以马克思主义为指导**。

（3）做好新闻舆论工作。

①做好新闻舆论工作的**第一位要求**：**坚持正确的政治方向**。

②新闻舆论工作的根本**原则**：**党性原则**。

③新闻舆论工作坚持党性原则**最根本的**是**坚持党对新闻舆论工作的领导**。

④社会舆论的**发射器和放大器**：**新闻媒体**。

⑤意识形态工作的**主阵地、主战场、最前沿**：**互联网**。

⑥新形势下做好新闻舆论工作的**关键**：**管好用好互联网**。

### 3. 铸就社会主义文化新辉煌 [p172]

（1）中华文明的突出特性：

| | |
|---|---|
| **连续性** | **从根本上决定了中华民族必然走自己的路** |
| **创新性** | **从根本上决定了中华民族守正不守旧、尊古不复古的进取精神，决定了中华民族不惧新挑战、勇于接受新事物的无畏品格** |
| **统一性** | **从根本上决定了中华民族各民族文化融为一体，决定了国土不可分、国家不可乱、民族不可散、文明不可断的共同信念，决定了国家统一永远是中国核心利益的核心，决定了一个坚强统一的国家是各族人民的命运所系** |
| **包容性** | **从根本上决定了中华民族交往交流交融的历史取向，决定了中国各宗教信仰多元并存的和谐格局，决定了中华文化对世界文明兼收并蓄的开放胸怀** |
| **和平性** | **从根本上决定了中国始终是世界和平的建设者、全球发展的贡献者、国际秩序的维护者，决定了中国不断追求文明交流互鉴而不搞文化霸权，决定了中国不会把自己的价值观念与政治体制强加于人，决定了中国坚持合作、不搞对抗，决不搞“党同伐异”的小圈子** |

（2）一个国家的文化软实力，**从根本上说**，取决于其**核心价值观的生命力、凝聚力、感召力**。

（3）提高中华文化影响力的**基本途径**：**讲好中国故事、传播好中国声音**。

## 理解部分

### 1. **文化的地位和作用** [p173]

文化是推动高质量发展的重要支点，能够为经济社会发展提供价值指引和精神支撑。推动文化融入经济活动，有助于激活发展动能、提升发展品质，增强社会创新创造活力。

> 命题思路：（1）注意不能把文化的作用夸大为解决发展问题的根本途径或决定性因素，也不能把文化建设的阶段性成果夸大为根本性变革，毕竟文化属于意识领域，并不能起到决定性作用。

例如：

- 错：文化建设是解决新时代我国社会主要矛盾的根本途径。
- 错：文化产业已经成为国民经济的支柱性产业。

### 2. **社会主义核心价值观** [p173]

（1）核心价值观是一个民族赖以维系的精神纽带，是一个国家共同的思想道德基础。

（2）社会主义核心价值观回答了我们要建设什么样的国家、建设什么样的社会、培育什么样的公民的重大问题。

> 命题思路：（1）注意不能泛化社会主义核心价值观的作用，它是我国社会主义制度的意识形态，不要将其与国际领域随意关联。

例如：

- 错：社会主义核心价值观是构建人类命运共同体的行动指南。

### 3. **文化事业与文化产业的关系** [p174]

| 分类 | 主导力量 | 功能定位 | 价值导向 |
|---|---|---|---|
| **文化事业** | 政府 | 满足基本文化需求 | 坚持把社会效益放在首位 |
| **文化产业** | 市场（企业） | 满足多样化文化需求 | 坚持把社会效益放在首位，社会效益和经济效益相统一 |

> 命题思路：（1）注意不能混淆文化事业与文化产业的主导力量、功能定位和价值导向。

例如：

- 错：发展经营性文化产业的根本任务是保障人民群众基本的文化权益。
- 错：大力发展公益文化产业，要始终坚持把经济效益放在首位。
