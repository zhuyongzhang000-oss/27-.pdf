# 马原 第三章 认识论

## 记忆部分

### 1. 实践 [p29]

（1）马克思主义理论区别于其他理论的**根本特征**：**实践性**。

（2）实践主体的能力包括自然能力和精神能力。

（3）精神能力包括知识性因素和非知识性因素。

（4）实践主体**首要的能力**：**知识性因素**。

（5）实践的中介系统包括物质性工具系统和语言符号工具系统。

（6）实践的**三种基本类型**：**物质生产实践（最基本的）、社会政治实践、科学文化实践**。

（7）实践的主体和客体相互作用的关系，包括实践关系、认识关系和价值关系，其中**最根本**的关系是**实践关系**。

（8）辩证唯物论的认识论之**第一的和基本的**观点：**实践的观点**。

（9）实践对认识的**决定作用**：**实践是认识的来源；实践是认识发展的动力；实践是认识的目的；实践是检验认识真理性的唯一标准**。

### 2. 认识的过程 [p29]

（1）感性认识的**形式**：**感觉、知觉和表象**。

（2）感性认识的**突出特点**：**直接性、具体性**。

（3）思维的细胞或**最基本**的思维形式：**概念**。

（4）理性认识的**形式**：**概念、判断、推理**。

（5）理性认识的**特点**：**间接性和抽象性**。

（6）认识过程中**更为重要**的一次飞跃：认识过程的**第二次能动的飞跃**。

（7）理性因素的作用：指导作用、解释作用和预见作用。

（8）非理性因素的作用：激活作用、驱动作用。

### 3. 真理和价值 [p30]

（1）真理的绝对性与相对性**根源于**：**人的认识能力、思维能力的矛盾本性**。

（2）人的认识能力、思维能力的**矛盾本性**：人的思维的**至上性**和**非至上性**或人的认识能力的**无限性**和**有限性**的矛盾。

（3）实践是检验真理的唯一标准，这是由**真理的本性和实践的特点**决定的。真理的本性是主观和客观的一致、符合。实践的特点是主观见之于客观的物质活动，具有直接现实性。

（4）在实践中人们必须遵循**正确反映客观事物本质和规律**的真理，这是指成功的实践必须遵循**真理尺度（合规律性）**。

（5）在实践中人们**都是按照自己的尺度和需要**去认识世界和改造世界，这是指成功的实践必须遵循**价值尺度（合目的性）**。

### 4. 必然和自由 [p30]

（1）人类认识世界和改造世界的**根本目标**：**认识必然和争取自由**。

（2）自由是历史发展的产物，**自由的条件**：一是**认识条件**；二是**实践条件**。

## 理解部分

### 1. **实践的本质和特点** [p30]

（1）实践的本质：实践是感性的、对象性的物质活动，是人类能动地改造世界的社会性的物质活动。

（2）实践的特征：

| | | |
|---|---|---|
| **客观实在性** | 实践能够引起客观世界的某种变化，可以把人脑中观念的存在变为现实的存在 | 侧重强调实践是“改造世界”的活动 |
| **自觉能动性** | 与动物本能的、被动的适应性活动不同，人的实践活动是一种有目的、有意识的活动 | 侧重强调实践是“发挥能动性”的活动 |
| **社会历史性** | 实践受一定社会历史条件的制约，随着一定社会历史条件的变化而变化 | — |

> 命题思路：（1）注意错误选项总是将实践表述为精神活动或者生物的本能活动。实践既能引起客观世界的变化，又体现着人们意识的能动性，这意味着实践也是人独有的活动，其他事物没有意识，也就不会实践，实践是人类独有的活动。

例如：

- 错：实践是主体自我实现的精神活动。
- 错：实践等同于生物适应环境的活动。
- 错：人工智能的实践极大地促进了生产力的发展。

### 2. **实践的基本结构** [p31]

| | | |
|---|---|---|
| **实践的结构** | 实践主体 | 指具有一定的主体能力、从事现实社会实践活动的人，是实践活动中自主性和能动性的因素 |
| **实践的结构** | 实践客体 | 指实践活动所指向的对象。实践客体与客观存在的事物不完全等同，客观事物只有在被纳入主体实践活动的范围之内、为主体实践活动所指向并与主体相互作用时才成为现实的实践客体 |
| **实践的结构** | 实践中介 | 指各种形式的工具、手段以及运用、操作这些工具、手段的程序和方法 |
| **主客体的关系** | 同构性 | 实践的主体和客体与认识的主体和客体在本质上是一致的。主客体之间最根本的关系是实践关系 |
| **主客体的关系** | 双向运动 | 主体客体化：人通过实践使自己的本质力量作用于客体，使其按照主体的需要发生结构和功能上的变化，形成了世界上本来不存在的对象物 |
| **主客体的关系** | 双向运动 | 客体主体化：客体从客观对象的存在形式转化为主体生命结构的因素或主体本质力量的因素，客体失去客体性的形式，变成主体的一部分 |

> 命题思路：（1）注意错误选项会扩大实践主体和实践客体的范围。实践主体并不是指“所有人”，实践客体也不是指“整个世界”。

例如：

- 错：实践主体是指一切人。
- 错：一切客观存在的事物都是实践客体。

> （2）注意错误选项会否认实践中介存在的必要性。不存在没有实践中介的实践活动，中介可以是“看得见”的物质工具，也可以是“看不见”的语言、程序和方法。

例如：

- 错：实践中介是可有可无的。

> （3）注意主体客体化和客体主体化是不可分割的两个方面，人类通过实践在改造世界，同时也在改造人本身，不能只看到主体客体化或只看到客体主体化。

例如：

- 错：实践的过程仅仅指的是主体客体化的过程。
- 对：实践的过程是主体客体化与客体主体化辩证统一的过程。
- 对：实践过程是一个主观见之于客观的过程。

### 3. **实践对认识的决定作用** [p33]

| | |
|---|---|
| **实践是认识的来源** | ①一切真知都是从直接经验发源的。<br>②一个人知识的获得，不外直接经验和间接经验两部分。就知识的本源来说，任何知识都不能离开直接经验，但是，这并不意味着事事都必须去直接经验，一个人的多数知识还是来自间接经验 |
| **实践是认识发展的动力** | 社会一旦有技术上的需要，这种需要就会比十所大学更能把科学推向前进 |
| **实践是认识的目的** | 认识指导实践、为实践服务的过程，即认识价值的实现过程 |
| **实践是检验认识真理性的唯一标准** | 此外再无别的标准 |

> 命题思路：（1）注意错误选项会颠倒实践和认识的关系。实践决定认识，认识指导实践，二者的关系不能颠倒，否则会犯唯心主义错误。

例如：

- 错：认识作为实践的基础必将不断推动实践的发展。

> （2）注意错误选项会将认识的获取方式单一化。认识来源于实践，实践是认识产生的唯一来源，这是从“归根到底”的层面来说的。但从每个具体的人获取认识的方式来说，却是多元化的，可以通过自身实践直接获取，也可以通过间接经验获取。

例如：

- 错：亲身实践是人们获取认识的唯一方式。

### 4. **认识的本质和规律** [p34]

| 项目 | 特征 | 派别划分 | 缺陷 / 优点 |
|---|---|---|---|
| **认识的本质** | 唯心主义先验论（坚持认识过程是“从思想和感觉到物”） | 主观唯心主义（认识是主观自生的） | 否认认识是人脑对客观世界的反映 |
| **认识的本质** | 唯心主义先验论（坚持认识过程是“从思想和感觉到物”） | 客观唯心主义（认识是上帝的启示） | 否认认识是人脑对客观世界的反映 |
| **认识的本质** | 唯物主义反映论（坚持认识过程是“从物到感觉和思想”） | 直观反映论（只要“反映”，不要“能动”） | ①离开实践考察认识问题，因而不了解实践对认识的决定作用。<br>②不了解认识的辩证本性，离开辩证法来考察认识问题。最根本的是它看不到主观和客观之间的矛盾及其相互作用，没有把认识看作一个不断发展的过程，而是认为认识是一次性完成的 |
| **认识的本质** | 唯物主义反映论（坚持认识过程是“从物到感觉和思想”） | 能动反映论（既要“反映”，又要“能动”） | ①把实践的观点引入认识论。<br>②把辩证法应用于反映论考察认识的发展过程，把认识看成一个由不知到知、由浅入深的充满矛盾的能动的认识过程，全面地揭示了认识过程的辩证性质 |
| **认识的规律** | 反复性 | — | 人们对于一个复杂事物的认识往往要经过由感性认识到理性认识、再由理性认识到实践的多次反复才能完成 |
| **认识的规律** | 无限性 | — | 认识表现为“实践—认识—再实践—再认识”的无限循环，是由初级阶段向高级阶段不断推移的永无止境的前进运动 |

> 命题思路：（1）注意错误选项会歪曲认识的本质，犯唯心主义或旧唯物主义错误。该考点只是对“意识”相关知识点的再现。在考研政治的题目中，意识就是认识，二者可以互相替代，对意识的理解完全可以迁移至此，所以二者的命题思路基本是相同的，但该考点更强调实践对认识的基础和决定性作用。

例如：

- 错：人的知识来源于对“理念世界”的认识和回忆。
- 错：人们消极地、被动地反映和接受外界对象。

### 5. **认识的过程（两次飞跃）** [p35]

（1）认识过程的第一次飞跃：从实践到认识。（从感性认识上升到理性认识）

| 项目 | 含义 | 形式 | 特征 |
|---|---|---|---|
| **感性认识** | 由感觉器官直接感受到的关于事物的现象、事物的外部联系、事物的各个方面的认识 | 感觉、知觉、表象 | 认识的初级阶段，具有直接性、具体性，不深刻 |
| **理性认识** | 借助抽象思维，在概括整理大量感性材料的基础上，达到关于事物的本质、全体、内部联系和事物自身规律性的认识 | 概念、判断、推理 | 认识的高级阶段，具有间接性、抽象性，更深刻、更正确、更完整 |
| **二者的辩证关系** | ①理性认识依赖于感性认识。感性认识是认识过程的起点。<br>②感性认识有待于发展和深化为理性认识。<br>③感性认识和理性认识相互渗透、相互包含 | ①理性认识依赖于感性认识。感性认识是认识过程的起点。<br>②感性认识有待于发展和深化为理性认识。<br>③感性认识和理性认识相互渗透、相互包含 | ①理性认识依赖于感性认识。感性认识是认识过程的起点。<br>②感性认识有待于发展和深化为理性认识。<br>③感性认识和理性认识相互渗透、相互包含 |

（2）认识过程的第二次飞跃：从认识到实践。（从理性认识上升到实践，更重要的飞跃）

> 命题思路：（1）注意错误选项会把感性认识和理性认识的关系表述为“对与错”的关系。感性认识是对现象的认识，理性认识是对本质的认识，二者只是“浅与深”的关系，而不是“对与错”的关系。

例如：

- 错：理性认识是人们对客观事物及其本质的正确认识。

> （2）注意错误选项会任意地说某哲学概念“更重要”。哲学概念之间不能说“谁更重要”，但可以说某个过程比另一个过程更重要。

例如：

- 错：感性认识比理性认识更重要。
- 错：物质比意识更重要。
- 对：认识过程的第二次能动的飞跃是更重要的一次飞跃。

### 6. **真理** [p37]

| | | |
|---|---|---|
| **真理的定义** | 人们对客观事物及其规律的正确反映 | 人们对客观事物及其规律的正确反映 |
| **真理的特性** | 客观性 | ①真理的内容是客观的。<br>②真理的标准是客观的（实践） |
| **真理的特性** | 一元性 | 同一条件下对于特定的认识客体的真理性认识只有一个，它不因主体认识的差别和变化而改变 |
| **真理的特性** | 绝对性 | ①真理必然正确，同谬误有原则的界限。<br>②人能够正确认识无限发展着的物质世界 |
| **真理的特性** | 相对性 | ①认识有待深化和扩展。<br>②任何真理都只能是主观对客观事物近似正确即相对正确的反映 |
| **错误观点** | 绝对主义 | 认为人们可以一下子穷尽绝对真理，把已有的理论看成永恒不变的教条。这种绝对主义在实际生活中表现为教条主义和思想僵化 |
| **错误观点** | 相对主义 | 怀疑科学理论的可靠性，把真理看作主观随意的东西。这种相对主义在实际生活中表现为怀疑主义和诡辩论 |
| **真理和谬误** | 区别 | 真理和谬误是性质不同的两种认识 |
| **真理和谬误** | 联系 | 真理和谬误相比较而存在，没有真理也无所谓谬误，没有谬误也无所谓真理；真理和谬误在一定范围内的对立是绝对的，超出这个范围，它们就会相互转化，真理变成谬误，谬误变成真理 |
| **真理的检验标准** | 实践是检验真理的唯一标准 | ①真理的本性是主观和客观的一致、符合。<br>②实践是主观见之于客观的物质活动，是沟通主观和客观的“桥梁” |
| **真理的检验标准** | 逻辑证明 | 只是探索真理、论证真理和扩大真理范围的重要手段和补充，本身不是检验真理的标准 |
| **实践标准的确定性与不确定性** | 确定性 | ①实践是唯一的标准。<br>②凡经过实践证明了的真理，都不可推翻。<br>③即便当下不能检验，未来也能检验 |
| **实践标准的确定性与不确定性** | 不确定性 | ①一定历史阶段上的具体实践具有局限性。<br>②检验不是一次完成的。<br>③已被实践检验过的真理还要继续经受实践的检验 |

> 命题思路：（1）注意错误选项会将真理（正确的认识）曲解为客观事物本身或纯粹主观的产物。首先，真理具有客观性，凡真理都是客观真理，但并不是说真理是一种客观存在。其次，真理既不是客观事物本身，也不是主观任意的，真理的内容是客观的、一元的，但形式是主观的、多样的。最后，真理之所以是真理，只取决于主观认识是否符合客观实际。

例如：

- 错：真理是客观存在的事物。
- 错：凡多数人承认的都是真理。

> （2）注意区分“相对真理”和“谬误”。相对真理是真理，未来有可能不对的性质和趋势，但是它现在还是正确的真理。而谬误则本身就是错的，现在就是错的。

例如：

- 错：相对真理指的是真理当中包含着错误的部分。

> （3）注意真理和谬误之间能不能转化，关键在于“范围”。同一范围内，二者有着严格的界限，不能相互转化，而超出范围，真理会转化为谬误，谬误会转化为真理。

例如：

- 错：在同一范围内，真理和谬误之间可以相互转化。

### 7. **价值** [p39]

| | | |
|---|---|---|
| **价值的定义** | 客体对个人、群体乃至整个社会的生活和活动所具有的意义 | 客体对个人、群体乃至整个社会的生活和活动所具有的意义 |
| **价值的基本特性** | 主体性 | ①价值关系的形成依赖于主体的存在。<br>②价值关系的形成依赖于主体的创造，使客体潜在的价值转化为现实的价值 |
| **价值的基本特性** | 客观性 | 价值是一种客观存在，独立于人们对它的认识和评价 |
| **价值的基本特性** | 多维性 | 同一客体相对于主体的不同需要会产生不同的价值 |
| **价值的基本特性** | 社会历史性 | 主体和客体以及主客体之间的关系发生变化，导致人们对客体价值的判断也发生改变 |
| **价值评价的特点** | 评价以主客体之间的价值关系为认识对象 | ①知识性认识：以客体本身的属性、关系和发展过程为反映内容，以获得关于客体的“真”的认识为目的。<br>②评价性认识：以客体和主体之间的价值关系为反映内容，以获得关于客体对于主体的意义，即“善”“美”的认识为目的 |
| **价值评价的特点** | 评价结果与评价主体直接相关 | 评价结果受到主体意志的影响 |
| **价值评价的特点** | 评价结果的正确与否依赖于知识性的认识 | 只有对主体和客体都有了正确认识，才能对主客体间的价值关系作出正确评价 |
| **价值评价的特点** | 评价分对错，对错有标准 | ①价值评价有科学与非科学之别。<br>②价值评价要以真理为根据，要有利于人类主体的生存和发展，与社会历史发展的客观规律相一致，推动社会历史进步，以最广大人民的需要和利益为根本 |

> 命题思路：（1）注意错误选项会把价值曲解为天然存在的。价值的主体性说明价值依赖于主体的创造，价值不会“自然显露”，而是依赖主体的主动创造，用类似“自发”“自然”“自动”的关键词来形容价值，均是错误的。

例如：

- 错：事物的价值会随着客体属性的自然显露而转化为社会价值。

> （2）注意错误选项会将价值曲解为主观任意的。价值具有主体性，价值确实始终以主体为中心，价值确实会随着主客体之间关系的变化而变化，但价值没有主观性，不会随着主体意志的变化而变化。比如，感冒药的作用是治感冒，这是客观的，不会因主体对感冒药的喜好和兴趣发生变化，价值不是“我觉得有用就有用”。另外，题目中也会对价值进行同义替换，如“意义”即价值。

例如：

- 错：事物的价值会随着主体的欲望、情感和兴趣的转移而变化。
- 错：世界上一切事物所具有的特定意义只是经验外化于对象的意义。

> （3）价值之所以是一种客观存在，重要原因之一是主体的需要是客观的。注意错误选项会将人们的需要归结为脱离客观实际的主观想象。人们的需要归根到底是客观的，与人们所处的客观条件和实践状况有直接关系，正如我们不会产生“登基称帝”的需要，古代帝王也不会产生“我要考研”的需要。

例如：

- 错：人们的需要取决于主体的观念和意志。

> （4）注意错误选项会将知识性认识和评价性认识的特点进行错配。

例如：

- 错：价值评价以客体本身的属性、关系和发展过程为反映内容。

> （5）注意错误选项会忽略价值评价的标准，将价值评价理解为主观任意的评价。尽管价值评价是主观评价，但也有客观标准。

例如：

- 错：价值评价没有科学和非科学之分。

### 8. **必然和自由** [p41]

（1）哲学上的自由是表示人的活动状态的范畴，是指人在活动中通过认识和利用必然所表现出的一种自觉自主的状态。自由是对必然的认识和对客观世界的改造。

（2）必然性即规律性，是指不依赖于人的意识而存在的自然和社会发展所固有的客观规律。

（3）认识必然和争取自由，是人类认识世界和改造世界的根本目标，是一个历史性的过程。由必然到自由表现为人类不断地从必然王国走向自由王国的过程。

（4）自由是历史发展的产物，自由是有条件的：一是认识条件；二是实践条件。

> 命题思路：（1）注意错误选项会把自由曲解为随心所欲的状态。马克思主义哲学认为不存在“绝对自由”，自由都是有条件的，因此不能忽略实现自由所需要的认识条件和实践条件。

例如：

- 错：“由自”等于“自由”，“由自”即随心所欲。
