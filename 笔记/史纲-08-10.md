# 史纲 第八～十章 新中国时期

## 记忆部分

**（一）从新民主主义向社会主义过渡的开始**

### 1. 中华人民共和国的成立及其伟大意义 [p253]

（1）**中华人民共和国的成立**，**彻底结束了旧中国半殖民地半封建社会的历史，彻底结束了极少数剥削者统治广大劳动人民的历史，彻底结束了旧中国一盘散沙的局面，彻底废除了列强强加给中国的不平等条约和帝国主义在中国的一切特权，实现了中国从几千年封建专制政治向人民民主的伟大飞跃。**

（2）中华人民共和国的成立**冲破了帝国主义的东方战线，极大地改变了世界的政治格局。**

（3）中华人民共和国的成立，是马克思列宁主义基本原理同中国革命具体实际相结合的思想——毛泽东思想的胜利。

### 2. 新民主主义社会的建立 [p253]

（1）中华人民共和国成立后**国情的变化**：**中华人民共和国的成立，标志着半殖民地半封建社会的结束和新民主主义社会在全国范围内的建立。**

（2）中华人民共和国成立后**革命性质的变化**：**中华人民共和国的成立，标志着我国新民主主义革命阶段的基本结束和社会主义革命阶段的开始。**

### 3. 完成民主革命遗留任务和恢复国民经济 [p254]

（1）中华人民共和国成立初期面临的困难。

**新生的共和国面临着两大任务**：**一是继续完成新民主主义革命的遗留任务，彻底解决中国人民同三大敌人的矛盾；二是动员人民努力医治战争创伤，恢复破败的国民经济。**

（2）中国共产党和人民政府的重点工作：

### 4. 开始向社会主义过渡 [p255]

（1）没收官僚资本，**确立社会主义国营经济在国民经济中的领导地位**。没收官僚资本，具有两重性质：**从反对外国帝国主义的附庸—中国的买办资产阶级——的意义上看，它具有民主革命的性质；从反对中国的大资产阶级的意义上看，它又具有社会主义革命的性质。**

（2）开始将资本主义纳入国家资本主义轨道。

（3）引导个体农民在土地改革后逐步走上互助合作的道路。

**（二）选择社会主义道路**

### 1. 过渡时期总路线的提出 [p255]

（1）中共中央领导人对向社会主义过渡设想的认识经历了一次大的改变：从“先工业化，再进行改造”变成了“一边工业化，一边进行改造”。

（2）**从“先化后改”变成“边化边改”的原因**：**一方面，随着民主革命遗留任务的彻底完成，国内的阶级关系和主要矛盾发生了深刻的变化；另一方面，随着国民经济的恢复和初步发展，中国社会的经济成分（即生产关系）发生了重要变化。**

（3）过渡时期的总路线：“一化三改”。

### 2. 实行社会主义改造的必要性和条件 [p256]

**（1）社会主义工业化是国家独立富强的首要条件。社会主义性质的国营经济力量相对来说比较强大，它是实现国家工业化的主要基础。**

**（2）资本主义经济力量弱小，发展困难，不可能成为中国工业起飞的基础。**

**（3）对个体农业进行社会主义改造，是保证工业发展、实现国家工业化的一个必要条件。**

**（4）当时的国际环境也促使中国选择社会主义。**

**（三）有中国特点的向社会主义过渡的道路**

### 1. 社会主义工业化与社会主义改造同时并举 [p256]

（1）社会主义工业化的目的：使中国富强。

（2）社会主义改造的目的：消灭资本家，消灭私有制，建立社会主义制度，使工业化沿着社会主义的方向进行。

（3）**“一五”期间工业化的成就**：**鞍山、包头、武汉三大钢铁基地的建设取得重大进展；武汉长江大桥通车；青藏、康藏、新藏公路建成通车。**

### 2. 农业的社会主义改造 [p256]

（1）**农业改造的步骤**：**第一，互助组，具有社会主义萌芽性质。第二，初级农业生产合作社，具有半社会主义性质。第三，高级农业生产合作社，具有完全的社会主义性质。**到1956年年底，农业合作化基本完成。

（2）**农业改造的道路**：**互助合作（合作化）。**

（3）农业合作化的方针：积极领导、稳步前进。

（4）农业合作化的原则：自愿互利、典型示范、国家帮助。

（5）农业合作化的方法：说服教育、典型示范、逐步推广、国家帮助。

（6）农业合作化是否办好的标准：是否增产。

（7）**“合作化”与“机械化”的关系**：**在实现农业合作化以后，国家应努力用先进的技术和装备发展农业经济。**

### 3. 手工业的社会主义改造 [p257]

（1）**手工业改造的步骤**：**第一，手工业生产合作小组，具有社会主义萌芽性质。第二，手工业供销合作社，具有半社会主义性质。第三，手工业生产合作社，具有完全的社会主义性质。**到1956年年底，手工业的合作化基本完成。

（2）手工业改造的方针：积极引导、稳步前进。

**（四）社会主义建设的初步探索**

### 1. 全面建设社会主义的开始 [p258]

（1）**社会主义改造基本完成后国情的变化**：**社会主义改造基本结束，社会主义经济制度和政治制度已经建立，马克思主义在意识形态领域占据了主导地位。这标志着我国完成了从新民主主义向社会主义的转变，进入了社会主义初级阶段，开始了全面建设社会主义的新时期。**

（2）**当时中国主要面临的两大问题**：**一个是如何处理好社会主义条件下的阶级斗争问题；另一个是如何处理好社会主义建设中的规模和速度问题。**

（3）**“第二次结合”的提出**：**社会主义制度确立以后，为了寻找一条适合中国情况的社会主义建设道路，毛泽东提出了把马克思列宁主义基本原理同中国具体实际进行“第二次结合”的任务。**

（4）**1957年4月27日，中共中央下发《关于整风运动的指示》**：决定在全党进行一次**反对官僚主义、宗派主义和主观主义的整风运动。**

### 2. 全面建设社会主义的成就 [p259]

**（1）建立了独立的比较完整的工业体系和国民经济体系。**

**（2）人民生活水平提高。**

（3）文化教育医疗体育和科学技术事业普遍发展：**1964年，第一颗原子弹爆炸；1967年，第一颗氢弹爆炸；1970年，第一颗人造地球卫星“东方红一号”发射；1972年，提取出一种新型抗疟药青蒿素；1973年，首次培育成功强优势的籼型杂交水稻。**

**（4）形成历久弥新的时代精神。**

**（5）国际地位提高与国际环境改善。**

**（五）中国特色社会主义开创、发展以及进入新时代**

### 1. 关于真理标准问题的讨论 [p259]

**对“真理标准问题的讨论”的评价**：**真理标准问题的讨论是继延安整风运动之后的又一场马克思主义思想解放运动，其实质在于是不是坚持马克思列宁主义、毛泽东思想。**

### 2. 中共十一届三中全会的伟大转折 [p260]

（1）《解放思想，实事求是，团结一致向前看》：这篇讲话，把解放思想、实事求是、坚持实践标准提高到党的思想路线的高度，为重新确立党的思想路线奠定了基础，因而成为开辟新时期新道路、开创建设有中国特色社会主义新理论的宣言书。

（2）中共十一届三中全会：作出了把工作重心转移到社会主义现代化建设上来和实行改革开放的战略决策。（其他内容见附录1）

### 3. 邓小平南方谈话 [p260]

**第一，计划和市场都是经济手段。第二，阐明了社会主义的本质。第三，提出了“发展才是硬道理”的重要论断。第四，提出判断改革开放和各项工作成败得失的“三个有利于”标准。第五，强调加强党的建设。第六，关于社会主义初级阶段的长期性和前途。**

## 理解部分

### 1. **新民主主义社会的基本特征** [p260]

**新民主主义社会**

|  |  |
|---|---|
| **政治** | **实行工人阶级领导的，以工农联盟为基础的，各革命阶级联合专政的政治制度** |

**经济**

|  |  |
|---|---|
| **国营经济占领导地位（社会主义经济）** | **三种独立经济成分** |
| **个体经济** | **三种独立经济成分** |
| **私人资本主义经济** | **三种独立经济成分** |
| **合作社经济（过渡性质）** | **两种过渡性质的经济** |
| **国家资本主义经济（过渡性质）** | **两种过渡性质的经济** |

|  |  |
|---|---|
| **文化** | 发展以马克思主义为指导的新民主主义的文化，即**民族的、科学的、大众的文化** |
| **阶级构成** | **工人阶级、农民阶级和其他小资产阶级、民族资产阶级** |
| **主要矛盾** | **中国完成了民主革命遗留任务并解决了土地问题以后**，中国还存在着两种基本矛盾：**国际上是新中国同帝国主义的矛盾；国内是工人阶级同资产阶级的矛盾** |
| **主要任务** | **反资反私（社会主义革命）** |

> 命题思路：（1）注意新民主主义社会仍然属于过渡性质的社会，是从属于社会主义体系的社会，并不是独立的社会形态。

例如：

- 错：新民主主义社会本质上处于社会主义初级阶段。
- 错：新民主主义革命的完成标志着我国进入了社会主义初级阶段。

> （2）注意新民主主义社会中的“独立经济成分”“过渡性质的经济”以及“领导地位”所对应的具体经济形式。

例如：

- 错：在新民主主义社会中，个体经济占领导地位。
- 错：新民主主义社会的国营经济主要是通过没收民族资本建立起来的。
- 错：新民主主义社会的个体经济属于社会主义性质的经济。

> （3）注意新民主主义社会中的主要矛盾是分阶段的，新解放区土地改革完成以前的主要矛盾是人民大众同帝国主义和封建主义残余势力的矛盾，土地改革完成后的主要矛盾变为工人阶级同资产阶级的矛盾。

例如：

- 错：新中国成立后，工人阶级和资产阶级的矛盾成为亟须解决的主要矛盾。

> （4）注意新民主主义社会的政权性质是各革命阶级联合专政，而不是无产阶级专政。

例如：

- 错：新民主主义社会的国家政权性质是无产阶级专政的社会主义国家。
- 错：新民主主义社会的国家政权仅仅代表工人阶级利益。
