# 马原 导论

## 记忆部分

### 1. 马克思主义的基本立场、基本观点和基本方法 [p2]

（1）**基本立场**：以**人民**为中心。

（2）**基本观点**：**关于自然、社会和人类思维发展一般规律的科学认识**。

（3）**基本方法**：**辩证唯物主义和历史唯物主义**。

### 2. 马克思主义产生的条件 [p2]

（1）**社会根源（经济社会背景）**：**资本主义生产方式有了相当的发展**。

（2）**阶级基础（实践基础）**：**无产阶级反抗资产阶级剥削和压迫的斗争**。

（3）**直接理论来源**：**德国古典哲学、英国古典政治经济学、英法两国的空想社会主义**。

### 3. 马克思主义的发展 [p2]

（1）列宁提出了社会主义革命可能在**一国或数国首先发生并取得胜利**的论断，其依据是**经济政治发展的不平衡**已成为资本主义发展的绝对规律。

（2）马克思主义创新发展的**基本路径**：**本土化和时代化**。

（3）习近平新时代中国特色社会主义思想的**世界观和方法论**：**必须坚持人民至上、坚持自信自立、坚持守正创新、坚持问题导向、坚持系统观念、坚持胸怀天下**。

### 4. “马恩列”经典著作总结 [p3]

（1）**《德意志意识形态》**：首次系统阐述（或创立）了**唯物史观**，标志着**马克思主义哲学**的诞生。

（2）**《资本论》**：系统阐述了**剩余价值理论**，标志着**马克思主义政治经济学**的诞生。

（3）**《共产党宣言》**：标志着**科学社会主义的诞生**；标志着**马克思主义的诞生**；是世界上第一个无产阶级政党的**党纲**。

（4）**《反杜林论》**：全面阐述了**马克思主义理论体系**。

（5）**《关于费尔巴哈的提纲》**：首次确立了**科学的实践观**。

（6）**《帝国主义是资本主义的最高阶段》**：**《资本论》**的直接继续，指出**帝国主义是无产阶级社会革命的前夜**。

（7）**《论欧洲联邦口号》**：首次明确提出**“一国胜利论”**。

### 5. 马克思主义的基本特征 [p3]

（1）马克思主义**首要的和基本的**观点是**实践观点**。

（2）马克思主义的基本特征，如果用**一句话来概括**就是**科学性与革命性**的统一。

## 理解部分

### 1. **克服非马克思主义观点** [p3]

| 马克思主义观点 | 非马克思主义观点 |
|---|---|
| “全世界无产者，联合起来” | “四海之内皆兄弟” |
| “共产主义” | “大同世界” |
| “共产主义” | “自由、平等、博爱的理性王国” |

> 命题思路：（1）注意题目会倾向考查对马克思主义的基本理解，错误选项往往会把非马克思主义观点强加给马克思主义，这类观点往往是资产阶级思想或古代封建思想。

例如：

- 错：马克思主义所追求的根本价值目标是建立一个自由、平等、博爱的理性王国。
- 错：马克思主义所追求的根本价值目标是建立一个四海之内皆兄弟的大同世界。
- 对：马克思主义所追求的根本价值目标是人的自由而全面的发展。

### 2. **马克思主义的基本特征** [p4]

| | |
|---|---|
| **科学性** | 马克思主义是对自然、社会和人类思维发展本质和规律的正确反映 |
| **人民性** | 马克思主义的本质属性，人民至上是马克思主义的政治立场 |
| **实践性** | 实践观点是马克思主义首要的和基本的观点 |
| **发展性** | 马克思主义是不断发展的开放的学说，具有与时俱进的理论品质 |

> 命题思路：（1）注意错误选项会曲解马克思主义“行”的根本原因。马克思主义的科学性是马克思主义之所以“行”的根本依据。科学社会主义和空想社会主义的根本区别就在于科学社会主义以唯物史观和剩余价值理论为基础，是科学的世界观和方法论。

例如：

- 错：马克思主义之所以“行”，根本原因在于马克思主义具有鲜明的政治立场。

> （2）注意马克思主义具有发展性，会不断发生变化，这是一个守正创新的过程。马克思主义的基本原则不会变，科学社会主义的基本原则不会变，但是某些具体做法和表现形式可以变。错误选项要么将马克思主义视为绝对不变的教条，要么认为马克思主义已经过时而要对马克思主义的基本原则进行修正。

例如：

- 错：我们可以适当修正马克思主义的基本原则。
- 错：马克思主义是关于客观世界和主观世界的终极真理。
