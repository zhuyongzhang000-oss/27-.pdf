# 习思想 导论

## 记忆部分

### 1. “两个结合” [p130]

（1）我们党在探索中国特色社会主义道路中得出的规律性认识、我们取得成功的**最大法宝**：**“两个结合”**。

（2）马克思主义能不能在实践中发挥作用，关键在于：①能否把马克思主义基本原理同中国实际和时代特征结合起来；②能否运用其科学的世界观和方法论解决中国的问题。

（3）马克思主义中国化时代化的**“魂脉”**：**马克思主义**。

（4）马克思主义中国化时代化的**“根脉”**：**中华优秀传统文化**。

### 2. 习近平新时代中国特色社会主义思想 [p130]

（1）回答的**时代课题**：①新时代坚持和发展什么样的中国特色社会主义、怎样**坚持和发展中国特色社会主义**；②建设什么样的社会主义现代化强国、**怎样建设社会主义现代化强国**；③建设什么样的长期执政的马克思主义政党、**怎样建设长期执政的马克思主义政党**。

（2）科学体系：

| 科学体系 | 地位 |
|---|---|
| **“十个明确”** | **构成了主体内容和四梁八柱，发挥着统摄作用** |
| **“十四个坚持”** | **构成了基本方略** |
| **“十三个方面成就”** | 展示了理论与实践成果 |
| **“六个必须坚持”** | 构成了世界观和方法论、彰显了理论品格和鲜明特征：<br>**①必须坚持人民至上：体现了历史唯物主义群众史观。**<br>**②必须坚持自信自立：体现了客观规律性和主观能动性的有机结合。**<br>**③必须坚持守正创新：体现了变与不变、继承与发展的内在联系。**<br>**④必须坚持问题导向：体现了矛盾的普遍性和客观性。**<br>**⑤必须坚持系统观念：体现了辩证唯物主义普遍联系的原理。**<br>**⑥必须坚持胸怀天下：体现了马克思主义追求人类进步和解放的崇高理想** |

（3）**历史地位**：①是马克思主义在当代中国发展的最新理论成果，实现了马克思主义中国化时代化新的飞跃；②是**中华民族的文化主体性最有力的体现**；③是全党全国各族人民为实现中华民族伟大复兴而奋斗的行动指南，是新时代党和国家事业发展的根本遵循。

（4）新时代党和国家事业取得历史性成就、发生历史性变革的**决定性因素**：**“两个确立”**。

## 理解部分

### 1. **“第二个结合”的内涵** [p131]

| | |
|---|---|
| **前提** | 彼此契合，中华优秀传统文化同马克思主义具有高度契合性 |
| **结果** | 互相成就，让马克思主义成为中国的，中华优秀传统文化成为现代的 |
| **意义** | ①筑牢了道路根基，让中国特色社会主义道路有了更加宏阔深远的历史纵深，拓展了中国特色社会主义道路的文化根基。<br>②打开了创新空间，是又一次的思想解放，让我们能够在更广阔的文化空间中，探索面向未来的理论创新和制度创新。<br>③巩固了文化主体性，表明我们党对中国道路、理论、制度的认识达到了新高度，历史自信、文化自信达到了新高度，在传承中华优秀传统文化中推进理论创新的自觉性达到了新高度 |

> 命题思路：（1）注意不能将“中华优秀传统文化同马克思主义之间存在高度契合性”曲解为一方对另一方的理论继承或完整体现。

例如：

- 错：中华优秀传统文化与马克思主义理论一脉相承。
- 错：中华优秀传统文化完整体现了马克思主义的立场、观点和方法。

> （2）注意一个非常重要的逻辑关系不能倒置：因为马克思主义与中华优秀传统文化具有契合性，它们才能结合，而不是因为它们结合了才有契合性。

例如：

- 错：“两个结合”使得马克思主义与中华优秀传统文化具有高度契合性。
