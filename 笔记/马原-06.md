# 马原 第六章 剩余价值论（发达商品经济）

## 记忆部分

### 1. 资本主义的产生 [p61]

（1）资本主义**产生的途径**：一是从**小商品经济**中分化出来；二是从**商人和高利贷者**转化而来。

（2）资本原始积累的**途径**：一是用暴力手段剥夺**农民的土地**；二是用暴力手段掠夺**货币财富**。

（3）劳动力成为商品，要具备**两个基本条件**：第一，劳动者在法律上是自由人，能够把自己的**劳动力**当作自己的商品来支配；第二，劳动者没有任何生产资料，没有别的商品可以出卖，“自由”得一无所有。

（4）**决定劳动力商品价值的是**：生产、发展、维持和延续**劳动力所必需的生活必需品**的价值。

（5）劳动力商品的价值由**三个部分构成**：第一，维持**劳动者本人生存**所必需的生活资料的价值；第二，维持**劳动者家属的生存**所必需的生活资料的价值；第三，劳动者**接受教育和训练**所支出的费用。

### 2. 剩余价值的生产 [p62]

（1）**资本主义生产过程的二重性**：一方面是**生产物质资料**的劳动过程；另一方面是**生产剩余价值**的过程，即价值增殖过程。

（2）**资本主义劳动过程的两个特点**：其一，工人在资本家的监督下劳动，他们的劳动隶属于**资本家**；其二，劳动成果或劳动产品全部归**资本家**所有。

（3）资本主义生产过程的主要**方面**：**价值增殖过程**。（剩余价值的生产过程）

（4）在价值增殖过程中，**雇佣工人的劳动分为两部分**：一部分是**必要劳动**，用于再生产劳动力的价值；另一部分是**剩余劳动**，用于无偿地为资本家生产剩余价值。

（5）**资本的本质**不是物，而是一定历史社会形态下的**生产关系**。

（6）资本家提高对工人剥削程度的方法是多种多样的，**最基本的方法**有两种，即**绝对剩余价值**的生产和**相对剩余价值**的生产。

（7）剩余价值的**唯一源泉**：**雇佣工人的剩余劳动**。

### 3. 剩余价值的积累（资本积累） [p62]

（1）**资本主义扩大再生产的源泉**：**资本积累**。

（2）**资本积累的源泉**：**剩余价值**。

（3）资本积累规模的大小**取决于**：资本家对工人的**剥削程度**、**劳动生产率**的高低、**所用资本和所费资本**之间的差额以及资本家**预付资本**的大小。

（4）资本主义社会失业现象产生的**根源**：**资本积累**。

（5）资本主义失业的**原因**：**资本积累导致资本有机构成提高，进一步形成相对过剩人口**。

（6）相对过剩人口的**三种形式**：**流动的**过剩人口、**潜在的**过剩人口、**停滞的**过剩人口。

（7）资本积累的**历史趋势**：**资本主义制度**的必然灭亡和**社会主义制度**的必然胜利。

### 4. 剩余价值的流通（资本的循环周转与再生产） [p63]

（1）产业资本在循环过程中要经历的**三个不同阶段**：**购买阶段、生产阶段、售卖阶段**。

（2）产业资本依次执行**三种不同职能**：**货币资本、生产资本、商品资本**。

（3）产业资本运动的**两个基本前提条件**：一是产业资本的三种职能形式必须在**空间上并存**；二是产业资本的三种职能形式必须在**时间上继起**。

（4）**影响资本周转快慢的因素**有很多，其中关键的因素有两个：一是**资本周转的时间**；二是生产资本中**固定资本和流动资本的构成**。

（5）社会再生产的**核心问题**：社会总产品的实现问题，即社会总产品的**价值补偿和实物补偿**问题。

（6）资本主义条件下以强制的方式解决社会再生产的实现问题的**途径**：**经济危机**。

### 5. 资本主义经济危机 [p64]

（1）马克思经济学说的**核心内容和基石**：**剩余价值理论**。

（2）资本主义经济危机的**本质特征**：**生产相对过剩**。

（3）经济危机的抽象的**一般的可能性**（形式上的可能性）：由**货币**作为支付手段和流通手段引起的。

（4）资本主义经济危机爆发的**根本原因**：**资本主义的基本矛盾**。

（5）资本主义的基本矛盾具体表现为**两个方面**：第一，**生产无限扩大的趋势**与**劳动人民有支付能力的需求相对缩小**的矛盾；第二，**单个企业内部生产的有组织性**和**整个社会生产的无政府状态**之间的矛盾。

### 6. 政治经济学计算公式大全 [p64]

| | | |
|---|---|---|
| **剩余价值率（剥削率）** | $m'=m/v$ | 剩余价值与可变资本的比值，或剩余劳动时间与必要劳动时间的比值 |
| **利润率** | 利润率 = 利润 / 成本 | 资本家把剩余价值视作总成本的增加额，此时剩余价值便转化为利润 |
| **资本有机构成** | $c:v$ | 不变资本与可变资本的比值 |
| **成本价格** | $c+v$ | 不变资本与可变资本之和 |
| **商品总价值** | $c+v+m$ | 不变资本、可变资本与剩余价值之和 |
| **生产价格** | 成本价格 + 平均利润 | — |
| **垄断价格** | 成本价格 + 平均利润 + 垄断利润 | — |

## 理解部分

### 1. **劳动力使用价值的特殊性** [p65]

劳动力商品在使用价值上有一个很突出的特点，就是它的使用价值是价值的源泉，在消费过程中能够创造新的价值，而且这个新的价值比劳动力本身的价值更大。

货币所有者购买到这种特殊商品以后，能够获得剩余价值，货币也就转化为资本。

在资本主义社会，资本家购买的是雇佣工人的劳动力而不是劳动。

> 命题思路：（1）注意劳动力商品的使用价值是劳动，这是它不同于其他商品的根本特征，劳动力的使用价值是价值的源泉，并且工人劳动创造的价值大于劳动力自身的价值（劳动力价值或工资）。工人创造的超过自身价值的那部分价值，就是资本家剥削的剩余价值。

例如：

- 对：劳动力商品的使用价值是价值的源泉。
- 错：劳动力商品在消费过程中只能创造出等同于劳动力自身价值的新价值。

> （2）注意错误选项会把“货币转化为资本的前提”歪曲成“商品变货币”。尽管就历史的前提来讲，货币只有产生了，才有可能变为资本，但这只是必要条件，而不是充分条件，最关键的在于劳动力变为商品，货币才能转化为资本。

例如：

- 错：只要商品转化为货币，货币就能转化为资本。

### 2. **剩余价值的实质** [p66]

假设：一件商品的价值为1 100元，包含生产资料价值900元，劳动力价值（工资）100元，利润100元。其中，生产资料价值是生产之前就存在的，工人经过8小时的劳动创造了200元新价值。

| 项目 | 前4小时 | 后4小时 |
|---|---|---|
| **两段劳动** | 必要劳动 | 剩余劳动 |
| **两种功能** | 生产劳动力价值（100元） | 生产剩余价值（100元） |
| **两个结局** | 工人获得工资 | 资本家获得利润 |

由此可见：

在价值增殖过程中，雇佣工人的劳动分为两部分：一部分是必要劳动，用于再生产劳动力的价值；另一部分是剩余劳动，用于无偿地为资本家生产剩余价值。因此，剩余价值（m）是雇佣工人所创造并被资本家无偿占有的超过劳动力价值的那部分价值，它是雇佣工人剩余劳动的凝结，体现了资本家与雇佣工人之间剥削与被剥削的关系。

> 命题思路：（1）注意错误选项会把工人获得的工资曲解为8小时的劳动创造的新价值。工人在生产过程中，先创造自己的劳动力价值（假设4小时生产劳动力价值），后生产剩余价值（假设4小时生产剩余价值），显然工资只是工人“4小时创造的价值”，而非“8小时创造的价值”。
>
> 但在资本主义制度下，工资是以货币的形式支付的，这就造成了一种假象，似乎工人的全部劳动都获得了报酬，这就掩盖了剥削。
>
> 总之，工人工资的本质是劳动力的价值或价格，而工资却表现为全部劳动的价值或价格，正因为其本质和表现形式不一样，所以，工资掩盖了剥削。

例如：

- 对：在资本主义制度下，工人的工资是劳动力的价值或价格。
- 错：在资本主义制度下，工人的工资是“劳动的价格”或工人全部劳动的报酬。
- 对：在资本主义制度下，工资之所以能掩盖剥削是因为它表现为“劳动的价格”或工人全部劳动的报酬。

> （2）注意错误选项会曲解剩余价值的本质和来源。剩余价值属于工人生产的新价值的一部分，而不是全部。剩余价值也是价值，其源泉只能是劳动、剩余劳动、抽象劳动，而不是资本家的总成本、必要劳动、具体劳动。

例如：

- 错：剩余价值来源于工人的必要劳动。
- 错：剩余价值来源于工人的具体劳动。
- 错：剩余价值来源于资本家的总投入。
- 错：在生产自动化条件下，剩余价值的来源不再是工人的劳动。

> （3）注意错误选项会把同步进行的两个方面曲解为“先后进行”。资本主义的生产过程具有二重性，在8小时内，从生产物质资料的角度来看，工人在不停地生产一个个商品；从生产剩余价值的角度来看，工人在源源不断地生产新价值。这两个方面是同时进行的，共同持续了8小时，总而言之，工人在生产物质资料的“同时”，也在生产新价值。

例如：

- 错：工人先生产商品的使用价值，再生产商品的剩余价值。
- 错：工人生产物质资料的时间就是生产剩余价值的时间。

### 3. **不变资本和可变资本** [p68]

根据资本在剩余价值生产过程中所起的不同作用，可以将资本划分为不变资本和可变资本。

| 项目 | 含义 | 符号 |
|---|---|---|
| **不变资本** | 以生产资料形态存在的资本 | $c$ |
| **可变资本** | 用来购买劳动力的那部分资本 | $v$ |
| **资本家总成本** | 不变资本 + 可变资本 | $c+v$ |

在资本主义社会中，工人劳动的两方面，分别承担的职能：

| | | |
|---|---|---|
| **具体劳动** | 本职功能 | 生产商品的使用价值，即生产物质资料 |
| **具体劳动** | 转移功能 | 转移生产资料的价值（c） |
| **抽象劳动** | 唯一功能 | 生产商品中的新价值（v+m） |

由此可见：

不变资本是以生产资料形态存在的资本，它通过工人的具体劳动被转移到新产品中去，其转移的价值量不会大于它原有的价值量。

可变资本是用来购买劳动力的那部分资本，在生产过程中不是被转移到新产品中去，而是由工人的劳动再生产出来。

> 命题思路：（1）注意错误选项会错配具体劳动和抽象劳动在资本主义生产过程中的功能，或者错配不变资本和可变资本“转化为商品价值”的方式。具体劳动干“两件事”：一是生产物质资料；二是转移生产资料的价值到新产品中。抽象劳动只干“一件事”，即生产新价值，这个新价值包含两部分：劳动力价值和剩余价值。

例如：

- 错：可变资本在生产过程中是被具体劳动转移到新产品中去的。
- 错：不变资本通过工人的抽象劳动被转移到新产品中。

### 4. **提高剩余价值的生产方法** [p69]

| 类别 | 含义 | 特点 |
|---|---|---|
| **绝对剩余价值** | 在必要劳动时间不变的条件下，由于延长工作日的长度或提高劳动强度而生产的剩余价值 | 必要劳动时间不变，工作日延长，没有技术或管理的进步 |
| **相对剩余价值** | 在工作日长度不变的条件下，通过缩短必要劳动时间而相对延长剩余劳动时间所生产的剩余价值 | 缩短必要劳动时间，不延长工作日长度，以全社会劳动生产率的提高为前提 |
| **超额剩余价值** | 企业由于提高劳动生产率而使商品的个别价值低于社会价值的差额 | 以提高个别劳动生产率为前提，不能长期获得，其客观后果是整个社会各个生产部门的劳动生产率普遍提高，最终导致相对剩余价值的产生 |

> 命题思路：（1）注意错误选项会错配三种剩余价值生产方法的特点。

例如：

- 错：绝对剩余价值的产生伴随着社会生产率的提高。
- 错：生产绝对剩余价值和相对剩余价值的共同点是二者都伴随着工作日的延长。
- 错：超额剩余价值可以长期获得。

### 5. **资本积累** [p70]

| | |
|---|---|
| **资本积累的含义** | 把剩余价值转化为资本，或者说剩余价值的资本化 |
| **资本主义简单再生产** | 生产在原有规模的基础上重复进行 |
| **资本主义扩大再生产** | 生产在扩大的规模上重复进行 |
| **资本积累的后果** | 社会财富占有两极分化 |
| **资本积累的后果** | 资本有机构成呈现不断提高的趋势（形成相对过剩人口） |
| **资本积累的后果** | 资本积累是资本主义社会失业现象产生的根源 |
| **资本技术构成** | 生产资料和劳动力之间的比例 |
| **资本价值构成（c:v）** | 不变资本和可变资本的比例 |
| **资本有机构成（c:v）** | 不变资本和可变资本的比例（由资本的技术构成决定并反映技术构成变化的资本价值构成） |

> 命题思路：（1）注意错误选项会曲解资本有机构成的提高。资本有机构成提高即c:v提高，而不是c或v在数量上绝对地提高或降低，也就是说资本有机构成的提高是可变资本相对量减少，资本对劳动力的需求日益相对地减少。

例如：

- 错：在资本主义条件下，工人的工资呈现不断降低的趋势。

> （2）注意错误选项会曲解相对过剩人口的含义。相对过剩人口是指不为资本增殖所需要的人口，即“失业人口”，而不是“绝对不被需要的人口”。

例如：

- 对：资本主义社会过剩人口之所以是相对的，是因为它不为资本价值增殖所需要。
- 错：资本有机构成的提高会导致绝对过剩人口的产生。

> （3）注意错误选项会曲解资本主义失业人口的特征。资本主义的失业是必然产生的，但是不代表失业规模会越来越大，而是会随着经济的发展呈现周期性变化。

例如：

- 错：资本积累使资本主义社会的失业人口规模呈现越来越大的趋势。

> （4）注意错误选项会忽视资本有机构成变化的前提。资本有机构成的变化必须由资本技术构成的变化导致，资本有机构成的提高本身就代表着资本主义生产水平的不断提高。资本当技术构成发生变化，资本价值构成一般也会发生变化，此时的资本价值构成是由技术变化引起的，故资本有机构成也发生了变化。若资本技术构成不发生变化，即便由于偶然因素（如原材料价格的变化）使得资本价值构成发生变化，资本有机构成也不会发生变化。

例如：

- 错：原材料价格的上涨会导致资本有机构成的提高。

### 6. **资本的循环周转与再生产** [p71]

| | |
|---|---|
| **资本循环** | 资本从一种形式出发，经过一系列形式的变化，又回到原来出发点的运动：三个阶段匹配三种职能。<br>①阶段：购买阶段—生产阶段—售卖阶段。<br>②职能：货币资本—生产资本—商品资本 |
| **资本周转** | 资本周而复始、不断反复的循环。<br>如果每次资本周转带来的剩余价值一定，则资本周转越快，在一定时期内带来的剩余价值就越多 |
| **社会再生产** | 社会总资本的再生产和流通。<br>两大部类：第Ⅰ部类，由生产生产资料的部门构成；第Ⅱ部类，由生产消费资料的部门构成 |

> 命题思路：（1）注意错误选项会混淆生产资本和商品资本的不同特点。生产资本是生产阶段的职能，负责生产剩余价值等；商品资本是售卖阶段的职能，负责实现剩余价值（以便于资本家拿到利润）。

例如：

- 错：生产资本负责实现剩余价值。

> （2）注意错误选项会混淆资本的分类，特别是不变资本和可变资本、固定资本和流动资本。

| 划分标准 | 划分结果 | 举例 |
|---|---|---|
| **资本循环中的职能** | 货币资本 | 大量货币 |
| **资本循环中的职能** | 生产资本 | 厂房和机器、奶牛、原材料（如肉牛）、劳动力 |
| **资本循环中的职能** | 商品资本 | 商品 |
| **是否增殖** | 不变资本 | 厂房和机器、奶牛、原材料（如肉牛） |
| **是否增殖** | 可变资本 | 劳动力 |
| **是否一次性转移或消耗** | 固定资本 | 厂房和机器、奶牛 |
| **是否一次性转移或消耗** | 流动资本 | 原材料（如肉牛）、劳动力 |

例如：

- 错：奶牛既是不变资本，又是流动资本。

> （3）注意错误选项会曲解两大部类的平衡问题。社会再生产的顺利进行，要求生产中所耗费的资本在价值上得到补偿，同时还要求实际生产过程中所耗费的生产资料和消费资料得到实物的替换，这在客观上要求两大部类内部各个产业部门之间和两大部类之间保持一定的比例关系。

| 类型 | 社会总价值 | 内部交换的部分 | 跨部类交换的部分 |
|---|---|---|---|
| **第Ⅰ部类（生产生产资料）** | Ⅰ(c) + Ⅰ(v) + Ⅰ(m) | Ⅰ(c) | Ⅰ(v) + Ⅰ(m) |
| **第Ⅱ部类（生产消费资料）** | Ⅱ(c) + Ⅱ(v) + Ⅱ(m) | Ⅱ(v) + Ⅱ(m) | Ⅱ(c) |
| **社会再生产顺利进行的条件** | Ⅱ(c) = Ⅰ(v) + Ⅰ(m) | Ⅱ(c) = Ⅰ(v) + Ⅰ(m) | Ⅱ(c) = Ⅰ(v) + Ⅰ(m) |

例如：

- 错：社会再生产的顺利进行要求Ⅰ(c) = Ⅱ(v) + Ⅱ(m)。

### 7. **剩余价值的分配（平均利润问题）** [p73]

| | |
|---|---|
| **平均利润的产生** | 不同部门之间如果利润率不同，资本家之间就会展开激烈的竞争，使资本从利润率低的部门转向利润率高的部门，从而导致利润率平均化，不同部门的资本家集团按照等量资本获得等量利润的原则来瓜分剩余价值。按照平均利润率来计算和获得的利润，叫作平均利润 |
| **平均利润的产生** | ①在利润率平均化的过程中，产业资本家获得产业利润，商业资本家获得商业利润，银行资本家获得银行利润，农业资本家获得农业利润。 |
| **平均利润的产生** | ②平均利润率规律反映了在瓜分剩余价值上，资本家之间存在竞争和矛盾，但在加强对工人阶级的剥削以榨取更多的剩余价值这一点上，资本家之间有着共同的阶级利益 |
| **生产价格** | 生产价格 = 生产成本（c+v）+ 平均利润 |
| **价值规律表现形式的变化** | 价格围绕生产价格自发波动 |

> 命题思路：（1）注意错误选项会把“部门间”的竞争歪曲为“部门内”的竞争。不同行业或部门之间的竞争是瓜分剩余价值、获得平均利润的过程，同一行业或部门内部即不同企业间的竞争是个别企业获得超额利润的过程。

例如：

- 错：平均利润率的产生是同一行业内部竞争的结果。

> （2）注意错误选项会混淆“借贷资本”和“具体职能资本”。具体职能资本包括产业资本、商业资本等，这些不同行业的资本家获得平均利润，而借贷资本不参与利润平均化的过程，借贷资本获得的是具体职能资本给他们的利息，当然，利润归根到底都来源于工人创造的剩余价值。

例如：

- 错：借贷资本会获得平均利润。

> （3）注意错误选项会曲解价值规律的变化。价值规律无论如何变化，都是其表现形式的变化，而非内容和实质的变化。

| | |
|---|---|
| **简单商品经济时期** | 价格围绕价值自发波动 |
| **自由竞争资本主义时期** | 价格围绕生产价格自发波动 |
| **垄断资本主义时期** | 价格围绕垄断价格自发波动 |

例如：

- 错：生产价格的形成导致价值规律的内容发生了实质性变化。

> （4）注意错误选项会曲解剩余价值和利润的关系。由于平均利润率规律的存在，不同行业的工人生产的剩余价值（生产时已确定）和最终各行业资本家获取的利润往往是不相等的。所以，剩余价值是“生产时凝结在商品中的钱”，利润是“最终拿到手的钱”，由于利润平均化的存在，二者往往是不一致的。但是，这种不一致只是不同行业资本家之间竞争的结果，社会上的剩余价值总量和利润总量总是一致的。

例如：

- 错：对于个别资本家而言，企业生产的剩余价值和获得的利润往往是一致的。
- 对：全社会的剩余价值总量和利润总量总是相等的。
