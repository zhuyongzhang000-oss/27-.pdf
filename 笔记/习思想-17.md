# 习思想 第十七章 全面从严治党

## 记忆部分

### 1. 新时代党的建设 [p189]

（1）新时代党的建设的**鲜明主题**：**全面从严治党**。

（2）新时代党的建设**总要求**：

| | |
|---|---|
| **原则** | **坚持和加强党的全面领导** |
| **方针** | **坚持党要管党、全面从严治党** |
| **主线** | **加强党的长期执政能力建设、先进性和纯洁性建设** |
| **统领** | **党的政治建设** |
| **根基** | 坚定理想信念宗旨 |
| **着力点** | 调动全党积极性、主动性、创造性 |
| **布局** | 全面推进党的政治建设、思想建设、组织建设、作风建设、纪律建设，把制度建设贯穿其中：<br>**①政治建设是党的根本性建设（摆在首位）。**<br>**②思想建设是党的基础性建设。**<br>**③纪律建设是全面从严治党的治本之策。**<br>**④制度建设是全面从严治党的长远之策、根本之策** |
| **重中之重** | 深入推进反腐败斗争，不断提高党的建设质量 |
| **目标** | 把党建设成为始终走在时代前列、人民衷心拥护、勇于自我革命、经得起各种风浪考验、朝气蓬勃的马克思主义执政党 |

（3）我们党作为马克思主义政党的**根本要求**：**旗帜鲜明讲政治**。

（4）党的政治建设的**首要任务**：**保证全党服从中央，维护党中央权威和集中统一领导**。

（5）作风问题的**核心**：**党同人民群众的关系问题**。

（6）新时代党的建设中，要**贯穿到党的各项建设之中**的是**制度建设**。

（7）关于“主线”的考点汇总：

| | |
|---|---|
| **全面深化改革的主线** | **制度建设** |
| **经济工作的主线** | **深化供给侧结构性改革** |
| **民族工作的主线** | **铸牢中华民族共同体意识** |
| **外交工作的主线** | **服务民族复兴、促进人类进步** |
| **“一带一路”的主线** | **互联互通** |
| **党建工作的主线** | **加强党的长期执政能力建设、先进性和纯洁性建设** |

### 2. 党的自我革命 [p190]

（1）危害党的生命力和战斗力的**最大毒瘤**：**腐败**。

（2）**最彻底的**自我革命：**反腐败**。

（3）跳出历史周期率的**第二个答案**：**党的自我革命**。

（4）实现伟大自我革命的**重要途径**：**自我净化、自我完善、自我革新、自我提高**。

### 3. 把权力关进制度笼子是新时代全面从严治党的一项重要任务，党的自我革命重在： [p190]

**治权**。

（出自习近平在二十届中央纪委五次全会上的重要讲话，2026年1月12日）

### 4. 全国党建工作座谈会 [p190]

（1）党的十八大以来，以习近平同志为核心的党中央围绕建设什么样的长期执政的马克思主义政党、怎样建设长期执政的马克思主义政党的重大时代课题，提出一系列新理念新思想新战略，形成习近平党建思想。

（2）习近平党建思想是加强新时代党的建设的根本遵循。

（出自全国党建工作座谈会的讲话，2026年6月15日）

| | |
|---|---|
| **中国式现代化区别于西方现代化的显著标志** | 全体人民共同富裕 |
