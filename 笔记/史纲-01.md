# 史纲 第一章 进入近代后中华民族的磨难与抗争

## 记忆部分

**（一）鸦片战争前后的中国与世界**

### 1. 鸦片战争的后果 [p194]

（1）**不平等条约**：**中英《南京条约》、中英《虎门条约》、中美《望厦条约》、中法《黄埔条约》**。

（2）**不平等条约的结果**：破坏了中国的**领土主权**；破坏了中国的**领海主权**；破坏了中国的**司法主权**；破坏了中国的**关税主权**；等等。

（3）**鸦片战争之所以成为中国近代史的起点**，是因为这场战争使得：第一，中国的国情发生变化，中国从一个封建国家逐步沦为**半殖民地半封建国家**；第二，中国社会的**主要矛盾发生变化**；第三，中国的革命任务发生变化，中国人民逐渐开始了**反帝反封建的资产阶级民主革命**。

（4）中国**没有完全沦为殖民地的原因**：第一，中国长期以来一直是一个统一的大国；第二，中国人民顽强、持久的反抗；第三，帝国主义列强间争夺中国的矛盾无法协调。

### 2. 近代中国的阶级状况 [p194]

（1）近代中国**最早产生的新阶级**，也是近代中国**最革命的阶级**：**工人阶级**。

（2）中国资产阶级是近代中国**新产生的阶级**，分为：**官僚买办资本家和民族资本家**。

### 3. 近代中国的基本国情和革命 [p195]

（1）近代中国的**基本国情**：**半殖民地半封建社会**。

（2）近代中国的**主要矛盾**：**帝国主义和中华民族的矛盾，封建主义和人民大众的矛盾**。

（3）近代中国的**主要任务**：**争取民族独立、人民解放。（反帝反封建）**

（4）近代中国的**革命性质**：**不是无产阶级社会主义革命，而是资产阶级民主主义革命**。

（5）近代中国的革命道路（新民主主义革命）：农村包围城市、武装夺取政权。

（6）近代中国的革命路线（新民主主义革命）：无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命总路线。

**（二）西方列强对中国的侵略**

### 1. 资本－帝国主义列强对中国的侵略，首先和主要的是： [p195]

**军事侵略**。

### 2. 列强侵略中国各个方面的表现 [p195]

| **方面** | **具体表现** |
|---|---|
| **军事侵略** | ①发动侵略战争，屠杀中国人民。<br>②侵占中国领土，划分势力范围。<br>③勒索赔款，抢掠财富 |
| **政治控制** | ①控制中国的内政、外交（把持中国海关）。<br>②镇压中国人民的反抗。<br>③扶植、收买代理人 |
| **经济掠夺** | ①控制中国的通商口岸。<br>②剥夺中国的关税自主权。<br>③实行商品倾销和资本输出。<br>④操纵中国的经济命脉 |
| **文化渗透** | ①披着宗教外衣，进行侵略活动。<br>②为侵略中国制造舆论（“种族优劣论”、中国“威胁”论） |

**（三）反抗外国武装侵略的斗争**

### 1. 中国近代史上中国人民第一次大规模的反侵略武装斗争： [p196]

**广州三元里人民的抗英斗争**。

### 2. 中日甲午战争和《马关条约》的相关内容 [p196]

（1）列强瓜分中国的狂潮到来的**标志**：**中日甲午战争和《马关条约》的签订**。

（2）中日甲午战争后，列强掀起了瓜分中国的狂潮，**表现在**：**竞相租借港湾和划分势力范围**。

（3）《马关条约》中割让给日本的中国领土：**台湾、澎湖列岛和辽东半岛**。

（4）**“干涉还辽”**事件：**俄、德、法**三国迫使日本放弃了割占辽东半岛的要求，又以干涉还辽“有功”为由，要求租借中国港湾作为报酬。

### 3. 列强瓜分中国图谋破产的原因 [p196]

第一，帝国主义列强之间的矛盾和互相制约是一个重要的原因；第二，**最根本的原因**是**中华民族进行的不屈不挠的反侵略斗争**。

### 4. 反侵略战争失败的原因 [p197]

第一，**社会制度的腐败**是**根本原因**；第二，经济技术的落后是重要原因。

## 理解部分

### 1. **近代中国沦为半殖民地半封建社会的原因** [p197]

（1）中国逐步沦为半殖民地的原因：第一，中国已经丧失了完全独立的地位，在相当程度上被殖民地化了；第二，近代中国仍然维持着独立国家和政府的名义，还有一定的主权。

（2）中国逐步沦为半封建社会的原因：第一，外国资本－帝国主义列强用武力打开中国的门户，把中国卷入世界资本主义经济体系和世界市场之中，中国出现了资本主义生产关系；第二，资本－帝国主义列强并不容许中国成为独立的资本主义国家，地主剥削农民的封建生产关系在社会经济生活中依然占据显然的优势。

> 命题思路：（1）注意“半殖民地”的原因和“半封建社会”的原因不能错配。“半殖民地”的原因主要涉及中国主权是否完整的问题，“半封建社会”的原因主要涉及封建经济是否仍是中国社会经济基础的问题。

例如：

- 错：中国沦为半殖民地的原因在于列强把中国卷入世界资本主义经济体系之中。

> （2）注意上文程度性词语的表述，如“相当程度上被殖民地化了”“封建生产关系依然占据显然的优势”会在命题中被夸大。

例如：

- 错：鸦片战争以后，随着资本－帝国主义的侵入，封建地主的土地所有制遭到彻底破坏。
- 错：鸦片战争以后，封建的中国逐步变成半封建的中国，所谓“半封建”是指封建经济占整个经济的一半。

### 2. **中国半殖民地半封建社会的基本特征** [p199]

| | |
|---|---|
| **政治方面** | ①资本－帝国主义侵略势力日益成为支配中国的**决定性力量**。<br>②封建势力成为资本－帝国主义压迫、奴役中国人民的**社会基础和统治支柱** |
| **经济方面** | ①封建剥削制度的根基即封建地主的土地所有制依然在广大地区内保持着。<br>②民族资本主义经济虽然已经产生，但发展很缓慢，力量很软弱 |
| **社会方面** | ①近代中国各地区经济、政治和文化的发展极不平衡（综合性说法）。<br>②广大人民尤其是农民日益贫困化，过着饥寒交迫和毫无政治权利的生活 |

> 命题思路：（1）注意半殖民地半封建社会在经济、政治和社会方面的表现不能错配。

例如：

- 错：中国半殖民地半封建社会在政治方面的表现是封建地主的土地所有制仍占绝对优势。

> （2）注意“决定性力量”和“社会基础”所对应的内容不能错配。通常，帝国主义对应的是“决定性力量”，封建势力对应的是“社会基础”。

例如：

- 错：封建势力日益成为支配中国的决定性力量。

### 3. **近代重要条约及其内容** [p199]

| **不平等条约** | **内容** |
|---|---|
| **1842年《南京条约》** | 把香港岛割让给英国 |
| **1858年《瑷珲条约》** | 割去黑龙江以北60万平方公里领土 |
| **1858年《天津条约》** | 允许外国公使常驻北京 |
| **1895年《马关条约》** | 割去中国台湾全岛及所有附属各岛屿和澎湖列岛，允许外国人在中国办工厂 |
| **1901年《辛丑条约》** | ①外国军队有权在北京使馆区和北京至大沽、山海关一线包括天津、唐山等12处“留兵驻守”。<br>②帝国主义列强还强迫清政府作出永远禁止中国人成立或加入任何反对它们的组织的承诺 |

> 命题思路：（1）注意条约内容和条约名称不能错配。尤其要关注“割让香港岛”“允许外国人在中国办工厂”“允许外国公使常驻北京”这些内容所对应的条约。

例如：

- 错：1842年的《南京条约》提出了允许外国公使常驻北京。
- 错：1858年的《天津条约》提出了允许外国人在中国办工厂。
