# 毛中特 第二章 新民主主义革命理论

## 记忆部分

### 1. 近代中国国情和中国革命的时代特征 [p94]

（1）解决中国革命问题的**基本前提**：**认清中国国情**。

（2）近代中国**最基本的国情**：中国逐步成为**半殖民地半封建社会**。

（3）占支配地位的主要矛盾：**帝国主义和中华民族**的矛盾、**封建主义和人民大众**的矛盾。

（4）各种矛盾中**最主要的矛盾**：**帝国主义和中华民族**的矛盾。

（5）中国革命的**性质**：资产阶级民主革命。

（6）为什么中国革命的性质是资产阶级民主革命：近代中国的**社会性质和主要矛盾决定了革命的对象是帝国主义和封建主义，革命的任务是反帝反封建。因此，无论是旧民主主义革命还是新民主主义革命，它的性质都只能是资产阶级民主主义革命**。

### 2. 新民主主义革命理论的实践基础 [p94]

（1）新民主主义革命理论的**形成**：**旧民主主义革命的失败**呼唤新的革命理论；**新民主主义革命实践**的需要，以及对**中国革命经验教训**的概括和总结。

（2）新民主主义革命理论得以形成的**基础和源泉**：**新民主主义革命实践**。

### 3. 新民主主义革命的总路线 [p95]

（1）**完整地总结和概括**新民主主义革命总路线内容的是：1948年毛泽东的**《在晋绥干部会议上的讲话》**。（其他内容见附录2）

（2）新民主主义革命总路线的**内容**：**无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命**。

（3）新民主主义革命的对象。

| | |
|---|---|
| **帝国主义** | **中国革命的首要对象。**<br>**中国社会进步和发展的最大障碍。**<br>**近代中国贫困落后和一切灾难祸害的总根源** |
| **封建主义** | **帝国主义统治中国和封建军阀实行专制统治的社会基础。**<br>**中国经济现代化和政治民主化的主要障碍，没有丝毫进步作用** |
| **官僚资本主义** | 依靠帝国主义、勾结封建势力、利用国家政权力量而发展起来的买办的、封建的国家垄断资本主义，严重束缚了中国社会生产力的发展 |

| 不同历史阶段 | 革命的主要对象 |
|---|---|
| **大革命时期** | 帝国主义支持下的北洋军阀 |
| **土地革命战争时期** | 国民党新军阀 |
| **抗日战争时期** | 日本帝国主义 |
| **解放战争时期** | 美帝国主义支持下的国民党反动派 |

（4）新民主主义革命的动力。

| 阶级 | 地位 | 阶级特点 |
|---|---|---|
| **无产阶级** | **中国革命最基本的动力** | 新的社会生产力的代表、近代中国最进步的阶级、中国革命的领导力量 |
| **农民阶级** | **中国革命的主力军。**<br>贫雇农是无产阶级最可靠的同盟军。<br>中农是可靠的同盟军 | **农民问题是中国革命的基本问题，新民主主义革命实质上就是中国共产党领导下的农民革命，中国革命战争实质上就是党领导下的农民战争** |
| **城市小资产阶级** | 无产阶级的**可靠同盟者** | 城市小资产阶级不属于资产阶级，它是劳动人民，属于先进阶级 |
| **民族资产阶级** | 中国革命的动力之一。<br>**带有两面性的阶级：革命性和动摇性（软弱性、妥协性）** | 中国共产党对民族资产阶级在经济上实行保护民族工商业的政策，在政治上争取它，对其动摇性和妥协性进行批评和斗争，既联合又斗争 |

（5）新民主主义革命的领导力量。

①**中国革命的中心问题、新民主主义革命理论的核心问题**：**无产阶级的领导权**。

|---|---|

| 中国革命的**首要**问题 | 分清敌友 |
| 中国革命的**基本**问题 | 农民问题 |
| 中国革命的**中心问题**，也是新民主主义革命理论的**核心问题** | 无产阶级的领导权问题 |
| 革命的**根本**问题 | 政权问题 |

②区别新旧两种不同范畴的民主主义革命的**根本标志**：**革命的领导权是掌握在无产阶级手中还是掌握在资产阶级手中**。

③中国革命取得胜利的**根本保证**：**无产阶级及其政党的领导**。

④无产阶级的优点：

| | |
|---|---|
| **各国共有** | 与先进的生产方式相联系；没有私人占有的生产资料；富于组织纪律性 |

⑤无产阶级及其政党对**中国革命的领导权**不是自然而然得来的，而是在**与资产阶级争夺领导权**的斗争中实现的。

⑥无产阶级领导权的实现：

| | |
|---|---|
| **条件** | 第一，率领同盟者向着共同的敌人作坚决的斗争，并取得胜利。<br>第二，对被领导者给以物质利益，至少不损害其利益，同时对被领导者给以政治教育 |
| **关键** | 必须建立以工农联盟为基础的广泛的统一战线 |
| **基本策略** | 在同资产阶级建立统一战线时，必须坚持独立自主的原则，保持党在思想上、政治上和组织上的独立性，实行又联合又斗争的方针 |
| **坚强支柱** | 建立一支无产阶级领导的以农民为主体的强大的革命武装 |
| **根本保证** | 加强无产阶级政党的建设 |

（6）新民主主义革命的性质和前途。

①新民主主义革命（与旧民主主义革命相比）有**新的内容和特点**。

| | |
|---|---|
| **时代特征** | **处于世界无产阶级社会主义革命的时代，是世界无产阶级社会主义革命的一部分** |
| **领导力量** | **中国无产阶级及其先锋队——中国共产党** |
| **指导思想** | **马克思列宁主义** |
| **前途** | **是社会主义而不是资本主义** |

②新民主主义革命与社会主义革命**性质不同**。

| 项目 | 新民主主义革命 | 社会主义革命 |
|---|---|---|
| **性质范畴** | **资产阶级民主主义革命** | **无产阶级性质的革命** |
| **目的** | **推翻帝国主义、封建主义和官僚资本主义，建立无产阶级领导的各革命阶级的联合专政** | **消灭资本主义的剥削，建立无产阶级专政** |
| **对资产阶级的态度** | **在政治上争取和联合民族资产阶级；在经济上保护民族工商业，容许有利于国计民生的私人资本主义发展** | **消灭资本主义剥削制度和改造小生产的私有制** |

③五四运动后，中国革命分**两步走**：第一步是完成**反帝反封建的新民主主义革命**任务，第二步是完成**社会主义革命**任务。

（1）毛泽东在**《〈共产党人〉发刊词》**中，提出了党在中国革命中战胜敌人的**三个主要的法宝**：**统一战线、武装斗争、党的建设**。（其他内容见附录2）

### 7. 新民主主义革命理论的意义 [p103]

（1）理论意义：揭示了近代中国革命发展的客观规律，解决了中国革命的一系列理论问题，科学地回答了中国革命向何处去的问题，以及中国革命的发展阶段问题，极大地**丰富了马克思主义的理论宝库**。新民主主义革命理论是马克思主义中国化时代化的重要理论成果，**开辟了马克思主义中国化时代化的发展道路**。

（2）实践意义：在新民主主义革命理论的指导下，党团结带领人民经过浴血奋战，**完成了新民主主义革命**，于1949年建立了中华人民共和国，实现了民族独立、人民解放。

（3）国际意义：**中国新民主主义革命的伟大胜利**，是20世纪继俄国十月革命以后改变世界面貌的伟大历史事件，也**极大改变了世界政治格局**，鼓舞了全世界被压迫民族和被压迫人民争取解放的斗争，极大地增强了他们反对帝国主义斗争的信心，**增强了世界人民争取和平的力量**。

## 理解部分

### 1. **新民主主义革命与旧民主主义革命的区别** [p103]

中国的旧民主主义革命属于世界资产阶级民主主义革命的一部分，十月革命之后，尽管中国的新民主主义革命本身不是无产阶级革命，但是已经属于世界无产阶级社会主义革命的一部分了。

> 命题思路：（1）注意新民主主义革命之所以属于世界无产阶级社会主义革命的一部分，是因为它发生在十月革命之后，发生在无产阶级社会主义革命的新时代。在命题的过程中可能会对这个说法进行错误归因。

例如：

- 错：新民主主义革命之所以属于世界无产阶级社会主义革命的一部分，是因为它是无产阶级性质的革命。
- 错：新民主主义革命之所以属于世界无产阶级社会主义革命的一部分，是因为它是无产阶级领导的革命。

### 2. **近代中国革命的任务** [p104]

近代中国革命的根本任务是推翻帝国主义、封建主义和官僚资本主义的统治，从根本上推翻反动腐朽的政治上层建筑，变革阻碍生产力发展的生产关系，为建设富强民主的国家、确立人民当家作主的政治制度、改善人民生活扫清障碍，创造必要的前提。

> 命题思路：（1）注意上述内容中提到了“两大任务”，一个是近代中国的任务：反帝反封建；还有一个是后续任务：国家富强、民族振兴、人民幸福。前一个任务是后一个任务的前提，也就是说，如果反帝反封建的任务没有完成，后续的任务是不可能完成的。而近代中国很多爱国人士提出的教育救国、科学救国、实业救国等主张，之所以会失败，都是因为他们忽略了反帝反封建这个前提。命题过程中，可能会对这个“前提”关系进行考查。

例如：

- 对：近代中国的教育救国、科学救国等主张之所以失败，原因都在于没有意识到争取民族独立、人民解放是实现国家富强、人民幸福的前提。

### 3. **新民主主义革命的对象** [p105]

帝国主义和封建主义相互勾结，中国革命“主要地就是打击这两个敌人，就是**对外推翻帝国主义压迫的民族革命和对内推翻封建地主压迫的民主革命**”。

> 命题思路：（1）注意帝国主义和封建主义是相互勾结的，帝国主义是封建地主阶级的靠山，地主阶级是帝国主义统治中国的主要社会基础。所以民族革命和民主革命两个基本任务，既相互区别，又相互统一。

例如：

- 对：如果不推翻帝国主义的统治，就不能消灭封建地主阶级的统治。
- 错：即使不推翻地主阶级，也能组织革命队伍推翻帝国主义在中国的统治。

### 4. **中国革命分“两步走”** [p105]

新民主主义革命与社会主义革命是互相联系、紧密衔接的，中间不容横插一个资产阶级专政。“民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势。”

> 命题思路：（1）注意区分“两步走”和“二次革命论”。后者主张在民主主义革命后先建立资产阶级共和国，待资本主义发展后再发动无产阶级社会主义革命，它割裂了民主主义革命和社会主义革命的联系，是右倾错误。

例如：

- 错：中国革命应该走先进行民主主义革命再进行社会主义革命的“二次革命”道路。

> （2）注意“毕其功于一役”的“一次革命论”是“左”倾错误，它混淆了民主主义革命和社会主义革命的界限。

例如：

- 错：中国革命要推翻豪绅地主阶级，便不能不同时推翻资产阶级。

> （3）注意新民主主义革命与社会主义革命紧密衔接，有一定的原因。新民主主义革命与社会主义革命虽然在任务、对象和性质方面有所不同，但它们在领导者、指导思想等方面是一致的，所以这“两步走”能够有机联系起来。

例如：

- 对：“两步走”之所以能成为一个整体，是因为民主主义革命中包含着社会主义革命的因素。
