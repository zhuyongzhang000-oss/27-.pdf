# 习思想 第二章 以中国式现代化全面推进中华民族伟大复兴

## 记忆部分

### 1. 实现中华民族伟大复兴的中国梦 [p136]

（1）中国梦：

| | |
|---|---|
| **本质** | **国家富强、民族振兴、人民幸福** |
| **关系** | ①国家富强、民族振兴是人民幸福的基础和保障。<br>②人民幸福是国家富强、民族振兴的根本出发点和落脚点 |

（2）坚持和发展中国特色社会主义的总任务：实现社会主义现代化和中华民族伟大复兴。

（3）全面建成社会主义现代化强国总的战略安排分两步走：①从2020年到2035年基本实现社会主义现代化；②从2035年到21世纪中叶把我国建成富强民主文明和谐美丽的社会主义现代化强国。

（4）我国发展的总体目标：

| | |
|---|---|
| **到2035年** | **①达到中等发达国家水平；实现高水平科技自立自强，进入创新型国家前列；建成现代化经济体系，形成新发展格局。**<br>**②建成教育强国、科技强国、人才强国、文化强国、体育强国、健康中国。**<br>**③全体人民共同富裕取得更为明显的实质性进展。**<br>**④广泛形成绿色生产生活方式，碳排放达峰后稳中有降，生态环境根本好转。**<br>**⑤全面建成高水平社会主义市场经济体制** |
| **到21世纪中叶** | **全体人民共同富裕基本实现** |

### 2. 中国式现代化 [p137]

（1）中国共产党团结带领中国人民追求民族复兴的历史，也是一部不断探索现代化道路的历史。

| 时期 | 对中国式现代化的作用 |
|---|---|
| **新民主主义革命时期** | **创造了根本社会条件** |
| **社会主义革命和建设时期** | **奠定了根本政治前提和制度基础，提供了宝贵经验、理论准备和物质基础** |
| **改革开放和社会主义现代化建设新时期** | **提供了充满新的活力的体制保证和快速发展的物质条件** |
| **新时代** | **提供了更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量** |

（2）中国式现代化的中国特色、本质要求和重大原则：

| | |
|---|---|
| **中国特色** | ①是人口规模巨大的现代化。<br>**②是全体人民共同富裕的现代化。**<br>③是物质文明和精神文明相协调的现代化。<br>④是人与自然和谐共生的现代化。<br>⑤是走和平发展道路的现代化 |
| **本质要求** | 坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态 |
| **重大原则** | 坚持和加强党的全面领导，坚持中国特色社会主义道路，坚持以人民为中心的发展思想，坚持深化改革开放，坚持发扬斗争精神 |

（3）中国式现代化区别于西方现代化的**显著标志**：中国式现代化是**全体人民共同富裕的现代化**。

（4）对中国式现代化的**定性（管总、管根本的）**：中国式现代化是**中国共产党领导**的社会主义现代化。

（5）中国式现代化创造了人类文明新形态：①提供了一种全新的现代化模式；②是对西方式现代化理论和实践的重大超越；③为广大发展中国家提供了全新选择。

## 理解部分

### 1. **推进中国式现代化需要正确处理的重大关系** [p138]

| | |
|---|---|
| **顶层设计与实践探索** | 顶层设计强调中央的谋篇布局；实践探索强调地方和基层的投石问路 |
| **战略与策略** | 战略强调全局性，要求坚持原则性；策略强调局部性，要求坚持灵活性 |
| **守正与创新** | 守正强调继承，要求确保正确方向；创新强调发展，要求顺应时代变化 |
| **效率与公平** | 效率强调解放和发展生产力，要求做大“蛋糕”；公平强调完善和发展生产关系，要求分好“蛋糕” |
| **活力与秩序** | 活力强调激发社会创新潜能；秩序强调确保国家长治久安 |
| **自立自强与对外开放** | 自立自强强调坚持独立自主，要求把发展的主动权牢牢掌握在自己手中；对外开放强调用好国内国际两种资源，要求在互利共赢中开创美好未来 |

> 命题思路：（1）“枫桥经验”是中国基层社会治理的典范，通过发动和依靠群众，实现矛盾不上交、就地化解矛盾、社会治安良好的治理模式。因此“枫桥经验”更侧重于对地方和基层治理经验的探索。

例如：

- 错：新时代“枫桥经验”最突出的特点是加强社会治理的顶层设计。

> （2）注意战略强调坚持原则性不动摇，策略强调坚持灵活性，二者不能错配。

例如：

- 错：统一战线中始终不变的是统战工作的具体政策策略。
