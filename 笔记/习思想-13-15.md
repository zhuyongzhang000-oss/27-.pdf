# 习思想 第十三～十五章 国家安全、国防军队和“一国两制”

## 记忆部分

### 1. 总体国家安全观 [p179]

（1）民族复兴的**根基**：**国家安全**。

（2）国家强盛的**前提**：**社会稳定**。

（3）总体国家安全观的内涵：

| | |
|---|---|
| **宗旨、基石** | **人民安全** |
| **根本、放在首要位置** | **政治安全** |
| **基础** | 经济安全 |
| **保障** | 军事、科技、文化、社会安全 |
| **依托** | 国际安全 |

### 2. 新安全格局 [p180]

（1）统筹发展和安全：①发展解决的是动力问题，是推动国家和民族赓续绵延的根本支撑；②安全解决的是保障问题，是确保国家和民族行稳致远的坚强柱石；③发展具有基础性、根本性，是解决安全问题的总钥匙，发展就是最大的安全；④安全是发展的条件和保障。

（2）构建新发展格局的**重要前提和保障**：牢牢守住**安全发展**这条底线。

（3）一个国家最根本的需求与一切国家生存和发展的**基础条件**：**政治安全**。

（4）政治安全与人民安全、国家利益至上是有机统一的：①政治安全是维护人民安全和国家利益的根本保证；②人民安全居于中心地位，国家安全归根到底是保障人民利益；③国家利益至上是实现政治安全和人民安全的要求和原则。

（5）构建新安全格局的**主阵地、主战场**：**维护重点领域国家安全**。

（6）我国公共安全治理模式的转型**主要**是：**以事后处置为主转向以事前预防为主**。

### 3. 新时代人民军队的使命任务和强军目标 [p181]

（2）党在新时代的**强军目标**：建设一支**听党指挥、能打胜仗、作风优良**的人民军队，把人民军队建设成为世界一流军队。

## 理解部分

### 1. **准确把握“一国两制”的科学内涵** [p183]

| | |
|---|---|
| **准确把握“一国”和“两制”的关系** | “一国”是实行“两制”的前提和基础；“两制”从属和派生于“一国”，并统一于“一国”之内 |
| **坚持全面管治权和高度自治权相统一** | 全面管治权是授权特别行政区高度自治的前提和基础；高度自治权是中央行使全面管治权的体现 |
| **坚持“爱国者治港”“爱国者治澳”** | 把特别行政区管治权牢牢掌握在爱国者手中，这是事关国家主权、安全、发展利益，事关香港、澳门长期繁荣稳定的根本原则 |
| **坚持依法治港治澳** | 宪法和基本法共同构成特别行政区的宪制基础；宪法是国家根本大法，是特别行政区制度的法律渊源 |

> 命题思路：（1）注意不能混淆特别行政区高度自治权的性质和来源。高度自治不是完全自治，也不是分权，而是中央授予的地方事务管理权。

例如：

- 错：特别行政区的高度自治权是特别行政区本身固有的权力。
- 错：特别行政区的高度自治权是中央授权之外的剩余权力。

> （2）注意不能把“一国两制”的原则底线和其他非原则问题相混淆，也不能把一般性问题随意上升为底线。任何危害国家主权安全、挑战中央权力和香港特别行政区基本法权威、利用香港对内地进行渗透破坏的活动，都是对底线的触碰。

例如：

- 错：干扰内地与香港的民间交流是我国处理香港问题绝不允许触碰的原则底线。
