# 思法 第二章 追求远大理想 坚定崇高信念

## 记忆部分

### 1. 理想的分类 [p269]

| **划分标准** | **类型** |
|---|---|
| **性质** | 科学理想和非科学理想 |
| **主体** | 个人理想和社会理想 |
| **阶段** | 近期理想和远期理想 |
| **层次** | 一般理想和崇高理想 |
| **内容** | 政治理想、道德理想、职业理想和生活理想 |

### 2. 信念的层次 [p269]

（1）**不同层次的信念的关系**：**高层次的信念决定低层次的信念，低层次的信念服从高层次的信念。**

（2）具有**最大统摄力**，也是**最高层次的信念**：**信仰。**

（3）信仰的性质：有盲目和科学之分。

### 3. 理想和信念的关系 [p269]

理想和信念总是相互依存。理想是信念所指的对象，信念则是理想实现的保障。

### 4. 坚持个人理想与社会理想的有机结合 [p270]

| **项目** | **个人理想** | **社会理想** |
|---|---|---|
| **地位** | 从属于社会理想 | 是在全社会占主导地位的共同奋斗目标；在整个理想体系中，是最根本、最重要的 |

|  |  |
|---|---|
| **关系** | **①个人理想以社会理想为指引。从根本上说，个人理想是由社会理想规定的。**<br>**②社会理想是个人理想的汇聚和升华。社会理想不是凭空产生的，也不是由外在力量强加的，而是建立在广大社会成员的个人理想基础之上的** |

## 理解部分

### 1. **理想和信念的特征** [p270]

|  |  |  |
|---|---|---|
| **理想的特征** | 超越性 | 理想不仅源于现实，而且超越现实 |
| **理想的特征** | 实践性 | 理想在实践中产生，在实践中发展，而且也只有在实践中才能得以实现 |
| **理想的特征** | 时代性 | 理想不仅受时代条件的制约，而且随着时代的发展而发展 |
| **信念的特征** | 执着性 | 信念一旦形成，就不会轻易改变 |
| **信念的特征** | 支撑性 | 信念是一个人经受实践考验而始终坚守理想的精神力量 |
| **信念的特征** | 多样性 | 不同的人会形成不同的信念，同时一个人在社会实践中会形成不同类型和层次的信念，并由此构成其信念体系 |

> 命题思路：（1）注意理解理想和信念的特征，考题可能会以人物事迹为题干，问“体现了理想信念的什么特征”。另外要特别注意，理想是对未来的追求，所以超越性是理想的特征。

例如：

- 错：红军长征的故事体现了信念具有执着性、支撑性、超越性。

### 2. **理想信念的作用** [p271]

理想信念是精神之“钙”，理想指引方向，信念决定成败；理想信念昭示奋斗目标、催生前进动力、提供精神支柱、提高精神境界。

> 命题思路：（1）注意“理想指引方向，信念决定成败”这句话只有原话出现在“思修”学科中才是正确的说法。在其他语境中，理想信念属于精神范畴，不具有决定性。

例如：

- 错：树立科学的理想信念是实现人生价值的决定因素。

### 3. **辩证看待理想与现实的矛盾** [p271]

理想与现实是对立统一的。理想和现实的矛盾与冲突属于“应然”和“实然”的矛盾。一方面，现实中包含着理想的因素，孕育着理想的发展。另一方面，理想中也包含着现实，既包含着现实中必然发展的因素，又包含着由理想转化为现实的条件，在一定的条件下，理想就可以转化为未来的现实。理想必须通过实践才能转变为现实。

> 命题思路：（1）注意“理想和现实”与“应然和实然”的对应关系。理想对应的是“应然”，现实对应的是“实然”。

例如：

- 错：理想和现实是相互对立的，理想是“实然”，现实是“应然”。

> （2）理想是对未来的向往，必然受到现实情况的制约，因此理想受到现实的规定和制约。

例如：

- 错：现实受到理想的制约。
