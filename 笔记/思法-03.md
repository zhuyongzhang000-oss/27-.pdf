# 思法 第三章 继承优良传统 弘扬中国精神

## 记忆部分

### 1. 中国精神的组成 [p272]

| **项目** | **民族精神** | **时代精神** |
|---|---|---|
| **形成** | 5000多年的历史发展进程 | 改革开放以来 |
| **核心** | **爱国主义** | **改革创新** |

|  |  |  |
|---|---|---|
| **关系** | **相互联系** | **二者都是中华民族赖以生存和发展的精神支撑；一切民族精神都曾经是一定历史阶段中带动潮流、推动社会发展的时代精神，同时，一切时代精神都将随着历史的变迁逐步融入民族精神之中** |
| **关系** | **相互区别** | **民族精神赋予中国精神以民族特征，是中华民族的精神独立性得以保持的重要保证；时代精神赋予中国精神以时代内涵，是中国精神引领时代前行、拥有鲜明时代性和强大生命力的重要根源** |

### 2. 爱国主义 [p272]

（1）爱国主义是调节**个人与祖国**之间关系的**道德要求、政治原则和法律规范**。

（2）爱国主义的**基本内涵**主要表现在四个方面：

|  |  |
|---|---|
| **爱祖国的大好河山** | 祖国的大好河山是主权、财富、民族发展和进步的基本载体 |
| **爱自己的骨肉同胞** | **骨肉同胞之爱反映了对民族利益共同体的自觉认同，是检验一个人对祖国忠诚程度的试金石** |
| **爱祖国的灿烂文化** | 文化是民族群体意识的载体，**是民族的“灵魂”“胎记”“精神基因”“摇篮”** |
| **爱自己的国家** | 国家是个体成长发展的基本屏障和坚实依托 |

（3）新时代爱国主义的**基本要求**：

|  |  |
|---|---|
| **坚持爱国爱党爱社会主义相统一** | 当代中国**爱国主义的本质** |
| **维护祖国统一和民族团结** | 弘扬新时代爱国主义的**着力点** |
| **尊重和传承中华民族历史文化** | **中华优秀传统文化是中华民族的精神命脉、文化基因，也是我们在世界文化激荡中站稳脚跟的根基** |
| **坚持立足中国又面向世界** | 当今世界，国家仍然是民族存在的最高组织形式，是国际社会活动中的独立主体 |

### 3. 改革创新 [p273]

（1）当代中国**最突出、最鲜明的特点**：**改革创新。**

（2）当代中国的显著特征、当代中国**最鲜明的特色**：**改革开放。**

（3）**改革开放的生命**：**创新。**

（4）当今国际竞争新优势的**集中体现**：**创新能力。**

## 理解部分

### 1. **中华民族崇尚精神的表现** [p274]

|  |  |
|---|---|
| **对物质生活与精神生活相互关系的独到理解** | 重视并崇尚精神生活：“不义而富且贵，于我如浮云”“道德当身，故不以物惑”“一箪食，一瓢饮，在陋巷，人不堪其忧，回也不改其乐”；见利思义、以义制利、先义后利；用道德理性和精神品格对欲望进行引导和控制；时刻对私欲、贪欲保持警惕 |
| **对理想的不懈追求** | 儒家把仁爱和谐视为最高理想，“志士仁人，无求生以害仁，有杀身以成仁”；墨家把“兼相爱，交相利”作为理想；无数志士仁人秉持“为天地立心，为生民立命，为往圣继绝学，为万世开太平”的理想等 |
| **对品格养成的重视** | ①关注人的精神品格：儒家把“君子”“圣人”作为自己的理想人格，道家推崇逍遥于天地之间的“真人”“至人”，近代启蒙思想家梁启超呼吁“新民”的理想人格。<br>②强调道德修养和道德教化，将“立德”置于“三不朽”（立德、立功、立言）之首。“自天子以至于庶人，壹是皆以修身为本”，教化的目的是“明人伦”，是培养有道德的人。<br>③不仅对道德修养和道德教化理论进行了系统论述，而且提出了修身养性的具体方法及家箴家训、乡规民约等教化方式 |

> 命题思路：（1）注意中华民族崇尚精神的三种表现与古诗文的对应。第二点和第三点容易混淆，第二点“对理想的不懈追求”体现的是“向外求”，向外求索、济世担当，第三点“对品格养成的重视”体现的是“向内求”，向内修炼、自我教化。

例如：

- 错：在中国传统文化中，把“君子”作为理想人格体现了中华民族对理想的不懈追求。

### 2. **中国精神的丰富内涵** [p275]

伟大创造精神、伟大奋斗精神、伟大团结精神、伟大梦想精神。

> 命题思路：（1）注意要紧密结合题干中的事例，将其与“四个伟大精神”进行精准匹配，尤其要区分“伟大奋斗精神”和“伟大梦想精神”，伟大奋斗精神侧重于勤劳勇敢，伟大梦想精神侧重于执着追求、不放弃。

例如：

- 错：盘古开天、神农尝草、精卫填海、愚公移山等中国古代神话体现了伟大奋斗精神。
- 对：中国人民始终革故鼎新、自强不息，开发和建设了祖国辽阔秀丽的大好山河，战胜了数不清的自然灾害，开垦了物产丰富的广袤良田，这是伟大奋斗精神的具体体现。

### 3. **中国精神的作用** [p275]

中国精神是凝聚中国力量的精神纽带；激发创新创造的精神动力；推进复兴伟业的精神支柱。

> 命题思路：（1）注意中国精神作为一种“精神”力量，其作用主要体现在“精神”层面。

例如：

- 对：中国精神是兴国强国之魂。
- 错：中国精神是实现第二个百年奋斗目标的根本途径。
- 错：个人成功的果实之所以应该结在爱国主义这棵常青树上，是因为爱国主义是个人成功的根本保障。

### 4. **爱国主义的特征** [p276]

（1）爱国主义是具体的、现实的。不同历史时期的爱国主义在内涵和表现方式上有所不同。爱国主义的丰富性和生命力，正是通过它的历史性和现实性来表现的。

（2）爱国主义随着国家的产生而产生，随着国家的发展而发展。在未来的共产主义社会，国家消亡后，爱国主义就会失去存在的条件和意义。

（3）在阶级社会中，爱国主义具有阶级性，不同的阶级对待祖国的感情，既有一致的方面，也有差异的方面，甚至有对立的方面。

> 命题思路：（1）注意爱国主义是具体的、现实的，是一个历史范畴。在阶级社会中，爱国主义具有阶级性。

例如：

- 错：无论是民主革命时期还是社会主义现代化建设时期，爱国主义的内涵始终一致。
- 错：爱国主义是永恒的。
- 对：在未来的共产主义社会，国家消亡后，爱国主义就会失去存在的条件和意义。
- 错：在阶级社会，不同阶级的爱国表现形式是一致的。
