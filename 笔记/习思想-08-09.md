# 习思想 第八～九章 中国特色社会主义民主与法治建设

## 记忆部分

### 1. 坚定中国特色社会主义政治制度自信 [p165]

（1）社会主义民主政治的**本质属性**是**全过程人民民主**。

（2）坚定中国特色社会主义制度自信，**首先要**坚定对**中国特色社会主义政治制度的自信**。

（3）中国特色社会主义政治制度的组成：根本政治制度、基本政治制度、重要政治制度。

（4）走中国特色社会主义政治发展道路的要求：

| | |
|---|---|
| **要求** | 必须坚持党的领导、人民当家作主、依法治国有机统一：**①党的领导是人民当家作主和依法治国的根本保证；②人民当家作主是社会主义民主政治的本质特征；③依法治国是党领导人民治理国家的基本方式** |
| **要求** | 必须积极稳妥推进政治体制改革 |
| **要求** | 必须始终保持政治定力 |

### 2. 全过程人民民主 [p165]

（1）全过程人民民主：①实现了过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志相统一；②是全链条、全方位、全覆盖的民主；③是最广泛、最真实、最管用的民主。

（2）实现全过程人民民主的**重要制度载体**：**人民代表大会制度**。

（3）实践全过程人民民主的**重要形式**：**协商民主**。

（4）全过程人民民主的**重要体现**：**基层民主**。

### 3. 健全人民当家作主的制度体系 [p166]

（1）**根本政治制度**：**人民代表大会制度**。

（2）人民代表大会制度：①是符合我国国情和实际、体现社会主义国家性质、保证人民当家作主的好制度；②是能够有效凝聚全体人民力量一道推进中国式现代化的好制度；③有效保证国家治理跳出治乱兴衰的历史周期率。

（3）人民代表大会制度的建立，意味着：①中国政治从根本上实现了由少数人掌握政权、绝大多数人受压迫被剥削到中国共产党领导、人民当家作主的伟大跨越；②实现了中国政治制度的伟大变革。

（4）**基本政治制度**：

| | | |
|---|---|---|
| **中国共产党领导的多党合作和政治协商制度** | **地位** | **我国的新型政党制度** |
| **中国共产党领导的多党合作和政治协商制度** | **方针** | **长期共存、互相监督、肝胆相照、荣辱与共** |
| **中国共产党领导的多党合作和政治协商制度** | **主题** | **团结和民主** |
| **中国共产党领导的多党合作和政治协商制度** | **职能** | **政治协商、民主监督、参政议政** |
| **民族区域自治制度** | **核心** | **保障少数民族当家作主，管理本民族、本地方事务的权力** |
| **民族区域自治制度** | **基本原则** | **维护祖国统一、反对民族分裂，坚持民族平等、民族团结、各民族共同繁荣** |
| **民族区域自治制度** | **主线** | **铸牢中华民族共同体意识** |
| **基层群众自治制度** | **地位** | **基层民主是社会主义民主政治建设的基础，是社会主义民主最广泛的实践** |
| **基层群众自治制度** | **职能** | **自我管理、自我服务、自我教育、自我监督** |
| **基层群众自治制度** | **特点** | **直接性** |
| **基层群众自治制度** | **基层自治组织** | **农村村民委员会、城市居民委员会、企业职工代表大会** |

（5）**人民政协**是：①最广泛的**爱国统一战线组织**；②**社会主义协商民主的重要渠道和专门协商机构**。

（6）中国社会主义民主政治中**独特的、独有的、独到的民主形式**：**协商民主**。

⑤是应对百年未有之大变局，增强中华民族凝聚力的重要举措。

### 5. 中国特色社会主义法治道路 [p169]

（1）治国理政的**基本方式**：**法治**。

（2）社会主义法治建设取得的历史性成就：全面依法治国总体格局基本形成。

（3）**中国特色社会主义法治道路的核心要义**，**就是要坚持党的领导，坚持中国特色社会主义制度，贯彻中国特色社会主义法治理论**。

**①党的领导是中国特色社会主义最本质的特征，是社会主义法治最根本的保证。**

**②中国特色社会主义制度是中国特色社会主义法治体系的根本制度基础，是全面推进依法治国的根本制度保障。**

**③中国特色社会主义法治理论是中国特色社会主义法治体系的理论指导和学理支撑，是全面推进依法治国的行动指南。**

（4）我们的法治同西方资本主义国家的法治**最大的区别**是**中国共产党的领导**。

（5）政治和法治关系的**集中反映**是**党和法的关系**。

### 6. 法治中国建设的总体目标 [p169]

（1）建设法治中国的总体目标，具体来说就是：到2035年，法治国家、法治政府、法治社会基本建成，中国特色社会主义法治体系基本形成，人民平等参与、平等发展权利得到充分保障，国家治理体系和治理能力现代化基本实现。

（2）我国法治区别于其他国家法治的**鲜明特征**是**把党内法规体系纳入中国特色社会主义法治体系**。

## 理解部分

### 1. **人大民主和基层民主** [p170]

| 民主类型 | 实现方式 | 管理对象 |
|---|---|---|
| **人大民主** | 间接民主 | 管理国家事务 |
| **基层民主** | 直接民主 | 管理基层事务 |

> 命题思路：（1）注意不能混淆人大民主与基层民主的民主类型、实现方式和管理对象。

例如：

- 错：发展基层民主为基层群众直接参与国家事务的管理提供了更多机会。

### 2. **社会主义协商民主** [p170]

（1）社会主义协商民主，是在中国共产党领导下，人民内部各方面围绕改革发展稳定重大问题和涉及群众切身利益的实际问题，在决策之前和决策实施之中开展广泛协商，努力形成共识的重要民主形式。

（2）选举民主和协商民主不是相互替代、相互否定的，而是相互补充、相得益彰的，共同构成了中国社会主义民主政治的制度特点和优势。其中，协商民主是中国社会主义民主政治中独特的、独有的、独到的民主形式，是中国特色社会主义民主政治的独特优势。

> 命题思路：（1）注意不能因为协商民主是中国特色社会主义民主政治的独特优势，就认为我国没有选举民主。

例如：

- 错：协商民主是社会主义民主政治的唯一形式。
