## 理解部分

### 1. **常见外交术语汇总** [p186]

| | | |
|---|---|---|
| **“伙伴”和“同盟”** | 伙伴关系 | 强调合作与发展，具有包容性和非强制性 |
| **“伙伴”和“同盟”** | 同盟关系 | 强调军事与安全，具有排他性和强制性 |
| **“南方”和“北方”** | 南方国家 | 指发展中国家 |
| **“南方”和“北方”** | 北方国家 | 指发达国家 |
| **“南方”和“北方”** | 南南合作 | 强调发展中国家之间的合作 |
| **“南方”和“北方”** | 南北对话 | 强调发展中国家同发达国家之间的谈判与协商 |
| **“单边”和“多边”** | 单边主义 | 强调某些大国从自身私利出发，无视国际共识、国际法和国际社会共同利益，单独依靠本国实力推行对外政策 |
| **“单边”和“多边”** | 多边主义 | 强调通过国际机制、国际协商处理国际事务，通过对话协商解决问题，不是一国单方面说了算 |

> 命题思路：（1）注意不能混淆外交术语的基本内涵，也不能曲解中国的对外政策取向。中国坚持不结盟政策，践行真正的多边主义，推动全球治理体系朝着更加公正合理的方向发展。

例如：

- 错：我国坚持中非盟友关系不会改变。
- 错：新兴市场国家与发展中国家对话会的举行进一步推动了南北对话。

> （2）注意不能把当今国际力量对比的深刻变化夸大为根本性变化。发展中国家群体性崛起、“全球南方”影响力提升是重要趋势，但国际力量对比的基本格局尚未发生根本改变，依然是发达国家在主导国际秩序。

例如：

- 错：“全球南方”国家在国际组织中的话语权和影响力占据了主导地位。

### 2. **我国走和平发展道路的依据** [p187]

| **维度** | **依据** |
|---|---|
| **制度属性** | 是由中国共产党的性质宗旨和我国社会主义制度决定的 |
| **历史文化** | 是基于中国历史文化传统作出的必然选择 |
| **时代背景** | 符合历史潮流、顺应世界大势 |

> 命题思路：（1）注意中国之所以走和平发展道路，在不同的维度，有不同的原因和依据，不能混淆。

例如：

- 错：坚持走和平发展道路，之所以符合中国的历史文化传统，是因为和平与发展成为时代发展的潮流。

### 3. **全人类共同价值和“普世价值”的区别** [p188]

（1）全人类共同价值是和平、发展、公平、正义、民主、自由，它是从世界各国、各民族价值观念中提炼出来的最大公约数，契合了时代发展的需要，体现了不同文明的价值共识，具有包容性和共通性。

（2）“普世价值”是西方主导的价值话语，实质是西方中心论，仅代表部分西方国家利益，依靠霸权向外输出，具有排他性、独断性和虚伪性。世界上不存在高人一等的“自由民主”，也不存在唯我独尊的“普世价值”。

（3）人类文明多样性是世界的基本特征，也是人类进步的源泉。不同文明凝聚着不同民族的智慧和贡献，没有高低优劣之分。要以文明交流超越文明隔阂，以文明互鉴超越文明冲突，以文明包容超越文明优越，不将自己的价值观和模式强加于人，不搞意识形态对抗。

> 命题思路：（1）注意不能美化和追求所谓的“普世价值”，也不能认为文明存在高低优劣之分。

例如：

- 错：马克思主义追求的根本价值目标是实现人类永恒不变的普世价值。
- 错：各种文明都具有独自的比其他文明更优越、更强大的文化基因。
