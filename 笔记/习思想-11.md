# 习思想 第十一章 以保障和改善民生为重点加强社会建设

## 记忆部分

### 1. 保障和改善民生 [p175]

（1）全面建设社会主义现代化国家的**出发点和落脚点**：**让人民生活越过越好**。

（2）**增进民生福祉**是：**①坚持立党为公、执政为民的本质要求；②社会主义生产的根本目的；③全面建设社会主义现代化国家的应有之义**。

（3）坚持在发展中增进民生福祉：

| | |
|---|---|
| **重要前提** | 正确把握民生和发展的关系：<br>①发展是改善民生的物质基础。<br>②抓民生也是抓发展，持续不断改善民生，能够有效解决群众后顾之忧，调动人们发展生产的积极性，增进社会消费预期，利于扩大内需，催生新的增长点 |
| **工作思路** | 坚守底线、突出重点、完善制度、引导预期 |
| **重中之重** | **解决人民群众最关心最直接最现实的利益问题** |
| **重要方针** | 坚持尽力而为、量力而行 |
| **重要原则** | 坚持人人尽责、人人享有，让所有劳动者在推动发展中分享发展成果 |

（4）不断提高人民生活品质：

| | |
|---|---|
| **完善分配制度** | **收入分配是民生之源，是改善民生、实现发展成果由人民共享最重要最直接的方式** |
| **实施就业优先战略** | **就业是最基本的民生，是最大的民生** |
| **健全社会保障体系** | **健全和完善社会保障体系是新时代加强社会建设的重要着力点** |
| **推进健康中国建设** | 人民健康是社会文明进步的基础，是民族昌盛和国家富强的重要标志 |

### 2. 推进社会治理现代化 [p176]

（1）既是进行社会治理的基础，也是提高社会治理效能的**保障**的是：**社会治理体系**。

（2）完善社会治理体系：①理念是先导；②制度是保障；③方式方法是重要内容。

（3）**社会治理理念**：**共建共治共享**。

（4）国家治理的**基石**：**基层治理**。

（5）既是社会治理最基本的单元，也是党和政府联系、服务居民群众的“最后一公里”的是：城乡社区。

## 理解部分

### 1. **促进高质量充分就业** [p176]

| | |
|---|---|
| **主要举措** | 深入实施就业优先战略，健全就业促进机制 |
| **主要举措** | 加强产业和就业协同，积极培育新职业新岗位 |
| **主要举措** | 完善人力资源供需匹配机制，健全终身职业技能培训制度 |
| **主要举措** | 完善就业支持和公共服务体系，稳定和扩大高校毕业生、农民工、退役军人等重点群体就业 |
| **主要举措** | 加大创业支持力度，增强创业带动就业效应 |
| **主要举措** | 完善劳动标准体系和劳动关系协商协调机制 |
| **主要举措** | 完善就业影响评估和监测预警 |

> 命题思路：（1）注意高质量充分就业的本质是要提升就业质量，而不是仅仅关注就业数量，如失业率和就业总人数。

例如：

- 错：使失业率保持在合理区间是我国提高就业质量的主要举措。
- 错：当前我国的就业问题主要在于就业岗位总量不足。
- 对：当前我国的就业工作要着力解决结构性就业矛盾。
