# 思法 绪论 担当复兴大任 成就时代新人

## 理解部分

### 1. **道德和法律的区别与联系** [p264]

| **项目** |  | **道德（德治）** | **法律（法治）** |
|---|---|---|---|
| **区别** | **地位不同** | 治国理政的**重要方式** | 治国理政的**基本方式** |
| **区别** | **调节范围不同** | 规范内心思想和外部行为 | 主要规范外部行为 |
| **区别** | **调节方式不同** | 主要**依靠社会舆论、道德评价的力量，依靠人们的内心信念、内在修养、传统习俗和社会教育的力量**来维持，是一种内在强制力 | **以国家强制力为坚强后盾，依靠强制手段来加以推行和实施，主要是一种外在强制力** |

|  |  |
|---|---|
| **联系** | **①都是调节人们思想行为、协调人际关系、维护社会秩序的重要手段，都是上层建筑的重要组成部分，共同服务于一定的经济基础。**<br>**②思想道德建设为法治建设提供思想指引和价值基础。**<br>**③法治建设为思想道德建设提供制度支撑和国家强制力保障** |

> 命题思路：（1）注意思想道德建设和法治建设在治国理政中的地位，二者既有区别又有联系，并不是“谁包含谁”的关系。只是在调节范围上，道德调节的范围更广，能够调节法律力所不及的问题。

例如：

- 错：思想道德建设与法治建设是包含与被包含的关系。
- 错：法律调节的范围比道德更广泛。

> （2）注意思想道德建设和法治建设在治国理政中的作用，思想道德更倾向于“软约束”，因此对应“思想指引、价值基础”等说法；法律更倾向于“硬约束”，因此对应“制度支撑、强制力保障”等说法。

例如：

- 错：法律倾向于为思想道德提供教化指引作用。
- 错：道德调节依靠国家强制力来保障实施。

> （3）注意法治建设为思想道德建设提供“制度支撑”，思想道德建设对法治建设也具有支撑作用。

例如：

- 对：思想道德建设与法治建设是相互支撑、相互促进的。
