# 史纲 第五章 中国革命的新道路

## 记忆部分

**（一）中国共产党对革命新道路的探索**

### 1. 土地革命战争的兴起 [p227]

（1）在革命的危急关头，中共中央政治局临时常委会决定了三件大事：一是将党所掌握和影响的部队向南昌集中，准备起义；二是组织湘、鄂、赣、粤四省的农民发动秋收起义；三是召集中央紧急会议，讨论和决定大革命失败后的新方针。

（2）**八七会议**：中国革命从此开始了**从大革命失败到土地革命战争兴起的转折。** （其他内容见附录1）

（3）三大起义：

|  |  |
|---|---|
| **南昌起义** | ①打响了武装反抗国民党反动派的第一枪。<br>②中国共产党独立领导革命战争、创建人民军队和武装夺取政权的开端 |
| **秋收起义** | ①公开打出了“工农革命军”的旗帜。<br>②进行三湾改编：从组织上确立了党对军队的领导。三湾改编是建设无产阶级领导的新型人民军队的重要开端 |
| **广州起义** | 对国民党的屠杀政策发动的又一次英勇反击 |

### 2. 农村包围城市、武装夺取政权道路的开辟 [p228]

（1）《中国的红色政权为什么能够存在？》和《井冈山的斗争》：深刻论证了红色政权能够长期存在并发展的主客观条件，提出了工农武装割据的思想。

（2）《星星之火，可以燎原》：提出了中国革命新道路的思想。

（3）《反对本本主义》：表现了毛泽东开辟新道路、创造新理论的革命首创精神。（其他内容见附录2）

（4）古田会议：确立了马克思主义建党建军原则，创造性地解决了在农村环境中、在党组织和军队以农民为主要成分的条件下，如何从加强思想建设入手，保持党的无产阶级先锋队性质和建设党领导的新型人民军队的重大问题。党对军队的绝对领导，是人民军队永远不变的军魂。这是人民军队完全区别于一切旧军队的政治特质和根本优势，对中国革命新道路的开辟和坚持具有重要意义。（其他内容见附录1）

（5）**毛泽东思想初步形成的标志**：**农村包围城市、武装夺取政权道路理论的提出，标志着中国化的马克思主义即毛泽东思想的初步形成。**

（4）“左”倾教条主义的主要错误：

|  |  |
|---|---|
| **在革命性质和统一战线问题上** | 混淆民主革命与社会主义革命的界限，将反帝反封建与反资产阶级并列 |
| **在革命道路问题上** | **继续坚持以城市为中心** |
| **在土地革命问题上** | **提出坚决打击富农和“地主不分田，富农分坏田”的主张** |
| **在军事斗争问题上** | **实行进攻中的冒险主义、防御中的保守主义、退却中的逃跑主义** |
| **在党内斗争和组织问题上** | 推行宗派主义和“残酷斗争”“无情打击”的方针 |

（5）**中国共产党在土地革命战争时期屡次犯错的原因**：第一，**八七会议后党内一直存在着浓厚的“左”倾情绪始终没有得到认真清理。**第二，**共产国际对中国革命的错误指导。**第三，**中国共产党不善于把马克思列宁主义与中国实际全面地、正确地结合起来（主要原因）。**

## 理解部分

### 1. **国民党在全国统治的建立及性质** [p230]

（1）国民党在全国建立统治的标志：1928年12月，张学良从东北发出通告，宣布“遵守三民主义，服从国民政府，改易旗帜”。国民党在全国范围内建立了自己的统治。

（2）大革命失败后的国民党政权的性质：代表地主阶级、买办性大资产阶级利益的反动集团。

> 命题思路：（1）注意大革命失败后的国民党政权代表地主阶级、买办性大资产阶级利益，依然是为帝国主义和封建势力服务的，因此大革命并没有完成反帝反封建的历史任务。

例如：

- 错：南京国民政府的统治代表民族资产阶级的利益。
- 错：国民党完成了反帝反封建的历史任务，实现了国家统一。
- 错：国民党政权彻底废除了帝国主义在华特权。

### 2. **土地革命战争时期的土地政策** [p231]

（1）土地革命的任务：消灭封建地主的土地私有制，实行农民的土地私有制，使广大农民在政治上得到翻身，农村生产力得到解放和发展。

（2）中国共产党历史上第一个土地法：《井冈山土地法》。

（3）中国共产党历史上第一个可以付诸实施的土地法：《兴国土地法》。将“没收一切土地”（《井冈山土地法》的不足之处）改为“没收一切公共土地及地主阶级的土地”。这是一个原则性的改正，保护了中农的利益，使之不受侵犯。

（4）土地革命中的阶级路线：坚定地依靠贫农、雇农，联合中农，限制富农，保护中小工商业者，消灭地主阶级。

（5）在大革命失败、白色恐怖极其严重的条件下，中国革命之所以能够得到坚持和发展，根本原因就在于：中国共产党紧紧地依靠农民，领导农民进行了土地制度的革命。

> 命题思路：（1）注意该时期的土地政策依然是实行农民土地私有制，而不是公有制。我国土地公有制的开端是1953年开始的农业社会主义改造。

例如：

- 错：土地革命废除了一切私有土地，实行土地国有。

> （2）注意该时期土地政策的调整过程，从《井冈山土地法》中的“没收一切土地”调整为《兴国土地法》中的“没收一切公共土地及地主阶级的土地”。特别注意，对待富农的态度是“限制富农”，而不是“消灭富农”。

例如：

- 错：土地革命战争时期，中国共产党在兴国制定的土地法采取了“消灭富农”的政策。

### 3. **遵义会议的结果与评价** [p232]

（1）遵义会议的结果：遵义会议集中解决了当时具有决定意义的军事和组织问题。会议决定成立由毛泽东、周恩来、王稼祥组成的三人小组，全权负责红军的军事行动。会议的一系列重大决策，是在中国共产党同共产国际联系中断的情况下独立自主地作出的。

（2）对遵义会议的评价：遵义会议是党的历史上一个生死攸关的转折点。这次会议事实上确立了毛泽东在党中央和红军的领导地位，开始确立以毛泽东为主要代表的马克思主义正确路线在党中央的领导地位，开始形成以毛泽东同志为核心的第一代中央领导集体，在最危急关头挽救了党、挽救了红军、挽救了中国革命。遵义会议开启了中国共产党独立自主解决中国革命实际问题的新阶段。

> 命题思路：（1）注意遵义会议的意义要同瓦窑堡会议、党的六届六中全会和中共七大等区别开。瓦窑堡会议的记忆关键词是“抗日民族统一战线”，党的六届六中全会的记忆关键词是“马克思主义的中国化”，中共七大的记忆关键词是“正式确立毛泽东思想”。

例如：

- 错：遵义会议提出了建立抗日民族统一战线的策略总方针。
- 错：遵义会议提出了“马克思主义的中国化”的命题。
- 错：遵义会议确立毛泽东思想为党的指导思想并写入党章。

> （2）注意遵义会议解决的问题仅限于军事领域和组织领域，并没有涉及思想领域和政治领域。

例如：

- 错：遵义会议彻底清算了王明“左”倾教条主义的思想根源。
- 错：遵义会议系统解决了党的政治路线问题。
