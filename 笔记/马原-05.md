# 马原 第五章 劳动价值论（简单商品经济）

## 记忆部分

### 1. 商品经济 [p53]

（1）商品经济产生的**社会历史条件**：一是**社会分工**的存在；二是**生产资料和劳动产品属于不同的所有者**。

（2）**“理解政治经济学的枢纽”**：**劳动二重性理论**。

（3）**影响劳动生产率的因素**主要包括劳动者的**平均劳动熟练程度**、**科学技术的发展水平**及其在生产中的应用程度、生产过程的**社会结合**、**生产资料的规模和效能**以及自然条件等。

（4）商品的价值形式的发展经历的**四个阶段**：**简单的或偶然的**价值形式、**总和的或扩大的**价值形式、**一般**价值形式以及**货币**形式。

（5）货币的两个**最基本的职能**：**价值尺度和流通手段**。

### 2. 价值规律 [p54]

（1）价值规律的**基本内容和客观要求**：商品的价值量由生产商品的**社会必要劳动时间**决定，商品交换以**价值量**为基础，按照**等价交换**的原则进行。

（2）价值规律的**表现形式**：商品的**价格围绕商品的价值自发波动**。

（3）价值规律的积极作用：第一，自发地调节生产资料和劳动力在社会各生产部门之间的分配比例；第二，自发地刺激社会生产力的发展；第三，自发地调节社会收入的分配。

（4）价值规律的消极作用：第一，导致社会资源浪费；第二，导致收入两极分化；第三，阻碍技术进步。

### 3. 商品经济的基本矛盾 [p54]

（1）以私有制为基础的商品经济的**基本矛盾**：**私人劳动和社会劳动的矛盾**。

（2）私人劳动和社会劳动之间的矛盾在资本主义制度下，**进一步发展成**：资本主义的基本矛盾，即**生产资料资本主义私人占有和生产社会化之间的矛盾**。

## 理解部分

### 1. **商品的定义** [p54]

商品是用来交换、能满足人的某种需要的劳动产品，具有使用价值和价值两个因素或两种属性，是使用价值和价值的矛盾统一体。

> 命题思路：（1）注意错误选项会忽略商品定义的其中一个维度，使商品退化为“普通劳动产品”或“自然物”。商品的定义指出，一个物品要想成为商品，必须满足两个条件：其一，必须是劳动产品（不可以是纯粹的自然物）；其二，必须以交换为目的进行生产（不可以是自己使用）。

例如：

- 错：中世纪农民为封建主生产的作为代役租的粮食是商品。
- 错：农民为养活家人而生产并消费的农副产品是商品。
- 错：自然界的阳光、空气和水是商品。

### 2. **商品的二因素：使用价值和价值** [p55]

| 项目 | 使用价值 | 价值 |
|---|---|---|
| **含义** | 指商品能满足人的某种需要的属性，即商品的有用性 | 凝结在商品中的无差别的一般人类劳动，即人的脑力和体力的耗费 |
| **属性** | 商品的自然属性，普通劳动产品、自然物共有的属性 | 商品的社会属性，商品特有的属性 |
| **来源** | 自然界和人的劳动都是使用价值的来源 | 劳动是价值的唯一源泉 |
| **与交换价值的关系** | 不同商品的使用价值的质是不同的，无法进行比较，无法决定交换价值。但使用价值是交换价值和价值的物质承担者 | 商品的价值在质上是相同的，因而可以相互比较，价值决定交换价值 |
| **关系** | ①二者不可兼得（对于商品生产者或购买者来说）；<br>②二者缺一不可（对于商品自身来说） | ①二者不可兼得（对于商品生产者或购买者来说）；<br>②二者缺一不可（对于商品自身来说） |

> 命题思路：（1）注意错误选项会曲解使用价值、价值和交换价值各自的特点或作用。

例如：

- 错：劳动是使用价值的唯一源泉。
- 对：劳动是价值的唯一源泉。
- 错：劳动是社会财富的唯一源泉。
- 错：使用价值决定交换价值。

### 3. **劳动的二重性** [p56]

| 项目 | 具体劳动 | 抽象劳动 |
|---|---|---|
| **含义** | 生产一定使用价值的具体形式的劳动，即有用劳动 | 撇开一切具体形式的、无差别的一般人类劳动，即人的脑力和体力的耗费 |
| **属性** | 劳动的自然属性 | 劳动的社会属性 |
| **和商品二因素的关系** | 具体劳动创造商品的使用价值 | 抽象劳动形成商品的价值，是商品价值的实体 |
| **关系** | 同一劳动的两种规定：任何一种生产商品的劳动，一方面是特殊的具体劳动，另一方面又是一般的抽象劳动 | 同一劳动的两种规定：任何一种生产商品的劳动，一方面是特殊的具体劳动，另一方面又是一般的抽象劳动 |

> 命题思路：（1）注意错误选项会错配具体劳动和抽象劳动的功能。具体劳动“各不相同”，于是创造了“各不相同”的使用价值；抽象劳动指“干啥都累”（都耗费脑力和体力），所以形成了商品的价值（商品的价值在质上是相同的，都是脑力和体力的耗费）。

例如：

- 错：具体劳动创造商品的价值。

> （2）注意错误选项会割裂具体劳动和抽象劳动的关系。正如商品的使用价值和价值无法割裂，具体劳动和抽象劳动是同一劳动的两个方面，而不是两次劳动或两个不同的劳动过程。

例如：

- 错：具体劳动和抽象劳动是前后相继的两次劳动。
- 错：具体劳动和抽象劳动是两种独立存在的劳动。
- 错：具体劳动和抽象劳动是不同劳动过程的不同形式。

### 4. **商品价值量的决定** [p57]

（1）个别劳动时间和社会必要劳动时间的比较。

| 劳动时间 | 作用 | 与劳动生产率的关系 |
|---|---|---|
| **个别劳动时间** | 不决定单位商品的价值量，决定单位时间内生产商品的数量 | 成反比：如生产单位商品的劳动时间减少意味着劳动生产率提高 |
| **社会必要劳动时间** | 既决定单位商品的价值量，也决定单位时间内生产商品的数量 | 成反比：如生产单位商品的劳动时间减少意味着劳动生产率提高 |

（2）商品价值量与劳动生产率的关系。

| 劳动生产率 | 单位商品的价值量 | 相同时间内生产商品的数量 | 商品价值总量 | 商品的使用价值总量（商品数量） |
|---|---|---|---|---|
| **社会（部门）劳动生产率提高** | 减少 | 增多 | 不变 | 增多 |
| **个别劳动生产率提高** | 不变 | 增多 | 增多 | 增多 |

> 命题思路：（1）注意错误选项会错配个别劳动生产率和社会劳动生产率的作用。个别劳动生产率不决定单个商品的价值量，但只要生产率提高，相同时间内的商品数量就会增多，故相同时间内商品的价值总量是增多的。
>
> 社会劳动生产率决定单个商品的价值量，也决定相同时间内的商品数量，故无论社会劳动生产率如何变化，相同时间内的价值总量是不变的。

例如：

- 错：无论个别劳动生产率如何变化，相同时间内商品的价值总量是不变的。

### 5. **简单劳动与复杂劳动** [p58]

商品的价值量同简单劳动和复杂劳动密切相关。

简单劳动是指不需要经过专门训练和培养的一般劳动者都能从事的劳动；复杂劳动是指需要经过专门训练和培养，具有一定文化知识和技术专长的劳动者所从事的劳动。

商品的价值量是以简单劳动为尺度的，复杂劳动等于自乘的或多倍的简单劳动。复杂劳动换算为简单劳动，是在商品交换过程中自发实现的。

> 命题思路：（1）注意错误选项会忽略前提条件，孤立地谈复杂劳动和简单劳动。复杂劳动的“含金量”更高，故“相同时间内”，复杂劳动创造的价值大于简单劳动创造的价值，不能忽略“相同时间内”这个前提。

例如：

- 错：复杂劳动创造的价值总是大于简单劳动创造的价值。

> （2）注意错误选项会把简单劳动和复杂劳动的换算曲解为人为规定的过程。复杂劳动换算为简单劳动，是在商品交换过程中自发实现的，也就是受市场规律影响、自然而然实现的，而不是人为主动规定的。

例如：

- 错：复杂劳动转化为简单劳动是商品生产者自觉计算出来的。
- 错：复杂劳动转化为简单劳动是市场管理部门事先规定的。
- 对：复杂劳动转化为简单劳动是商品交换过程中市场机制自发实现的。

### 6. **价值的表现形式（货币及其职能）** [p59]

| | | | |
|---|---|---|---|
| **货币的定义** | 货币是在长期交换过程中形成的固定充当一般等价物的商品 | 货币是在长期交换过程中形成的固定充当一般等价物的商品 | 货币是在长期交换过程中形成的固定充当一般等价物的商品 |
| **货币的职能** | 最基本的职能 | 价值尺度 | 衡量其他商品价值的职能，此时货币可以是观念上的货币 |
| **货币的职能** | 最基本的职能 | 流通手段 | “一手交钱一手交货”的交易，此时货币必须是现实的货币，但货币可以不足值 |
| **货币的职能** | 其他职能 | 支付手段 | “钱货不同步”的交易，存在债务关系，此时货币必须是现实的货币，但货币可以不足值 |
| **货币的职能** | 其他职能 | 贮藏手段 | 货币退出流通领域，作为社会财富的一般代表贮藏起来 |
| **货币的职能** | 其他职能 | 世界货币 | 货币的各种职能在国际交易中发挥作用 |

| | | |
|---|---|---|
| **货币产生后的商品世界** | 分化为两极 | ①一极是各种各样的具体商品，分别代表不同的使用价值；另一极是货币，只代表商品的价值。<br>②商品内在的使用价值和价值的矛盾就转化为商品和货币的外在矛盾。<br>③货币的出现有利于解决商品交换的困难，促进了商品经济的发展。但是，货币的出现并没有从根本上消除商品经济的矛盾，反而有可能使矛盾扩大和加深。<br>④“商品的惊险的跳跃”：商品转换成货币 |

> 命题思路：（1）注意区分“现实的货币”和“观念上的货币”。由于价值尺度仅仅是衡量商品价值的一种功能，所以只需要“观念上的货币”即可，其他手段均需要“现实的货币”。

例如：

- 错：货币在执行支付手段时可以是观念上的货币。

> （2）注意区分“足值的货币”和“不足值的货币”。价值尺度是“衡量”商品价值的功能，所以货币必须是足值的，才能“平衡”。流通手段和支付手段都是“使用货币”，所以只要每个人拿到货币能用出去，就可以无视货币是否足值的问题，即使现代社会中纸币没有任何“含金量”，但依然可以代表货币，执行流通手段或支付手段的职能。此外，在马克思主义政治经济学的定义中，当金银等贵金属固定下来充当一般等价物时，便称之为货币。

例如：

- 错：货币在执行流通手段时必须是足值的贵金属。
- 对：金银天然不是货币，但货币天然是金银。

> （3）注意区分“流通手段”和“支付手段”。流通手段指钱货同步的交易，使货币“流通起来”。支付手段指存在债务关系的交易，如买东西赊账，以后再还钱（支付）。

例如：

- 错：货币在发放工资中执行流通手段的职能。

> （4）注意错误选项会曲解货币出现后商品世界的变化。货币能够购买所有商品，货币的出现加速和扩大了商品的交换，但并不能缓解商品交换的矛盾，反而扩大了这种矛盾。

例如：

- 错：货币的出现解决了商品经济的矛盾。
