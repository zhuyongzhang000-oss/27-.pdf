# 习思想 第一章 新时代坚持和发展中国特色社会主义

## 记忆部分

### 1. 中国特色社会主义的性质、表现和底气根基 [p132]

（1）关系党的事业兴衰成败**第一位的问题**：**道路问题**。

（2）一个国家实行什么样的主义，关键要看这个主义能否解决这个国家面临的**历史性课题**。

（3）马克思主义传入中国后，科学社会主义的主张受到中国人民热烈欢迎，并最终扎根中国大地、开花结果，决不是偶然的，而是因为它：①回答了近代以来中华民族面临的历史性课题、指明了实现伟大复兴的正确道路；②同我国传承了几千年的优秀历史文化和广大人民日用而不觉的价值观念具有高度的契合性。

（4）马克思主义的**核心内容**：**科学社会主义基本原则**。

（5）改革开放以来我们取得一切成绩和进步的**根本原因**，归结起来就是：①开辟了**中国特色社会主义道路**（实现途径）；②形成了**中国特色社会主义理论体系**（行动指南）；③确立了**中国特色社会主义制度**（根本保障）；④发展了**中国特色社会主义文化**（精神力量）。

（6）“四个自信”的来源、根基和底气：

| | |
|---|---|
| **坚实根基** | **深厚的实践基础和人民的广泛参与、深切认同** |
| **理论支撑和根本依据** | **马克思主义深刻揭示了社会主义必然代替资本主义的客观规律** |
| **最大优势** | **中国共产党的坚强领导** |
| **发展优势** | **更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量** |
| **文化根脉和突出优势** | **连绵不绝的中华5000多年文明** |

（7）我们说要坚定中国特色社会主义道路自信、理论自信、制度自信，**说到底是要坚定**：**文化自信**。

### 2. 中国特色社会主义进入新时代 [p133]

（1）新时代的主要矛盾：

①我们党作出中国特色社会主义进入新时代重大判断的**基本依据**：**我国社会主要矛盾的变化**。

②我国**社会主要矛盾**已由人民日益增长的物质文化需要同落后的社会生产之间的矛盾，转化为：**人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾**。

③满足人民日益增长的美好生活需要的**主要制约因素**：**发展不平衡不充分问题**。

（2）新时代我国社会主要矛盾的变化，没有改变对**我国社会主义所处历史阶段**的判断（“两个没有变”）：①我国仍处于并将长期处于社会主义初级阶段的**基本国情**没有变；②我国是世界最大发展中国家的**国际地位**没有变。

（3）我们党坚定信仰信念、把握历史主动的**根本所在**：拥有**马克思主义科学理论**指导。

## 理解部分

### 1. **新的历史方位和发展阶段** [p134]

中国特色社会主义新时代是我国发展新的历史方位，标志着中国特色社会主义事业进入了新的发展阶段。

| | |
|---|---|
| **新的历史方位** | 从中华民族伟大复兴的历史进程看，意味着近代以来久经磨难的中华民族迎来了从站起来、富起来到强起来的伟大飞跃，迎来了实现中华民族伟大复兴的光明前景 |
| **新的发展阶段** | 从社会主义初级阶段的长期性与阶段性相统一看，我国经济已由高速增长阶段转向高质量发展阶段，要着力解决好发展不平衡不充分问题，大力提升发展质量和效益 |

> 命题思路：（1）注意不能把新时代对党和国家工作提出的新要求等同于已经取得的历史性成就。当前我国经济社会发展要以“高质量发展”为主题，但这并不意味着我国已经实现了高质量发展。

例如：

- 对：我国经济已经实现了由高速增长向高质量发展的转变。
- 错：我国经济已经完成了高质量发展的任务。

> （2）注意我国仍处于社会主义初级阶段的基本国情没有变，主要原因是我国总体上仍处于不发达阶段，归根到底是中国内部的原因，而不是各种外部环境的原因。

例如：

- 错：我国社会主义所处历史阶段没有变的依据是我国仍然面临极其复杂的国际环境。

> （3）注意不能把我国社会主要矛盾的变化等同于主要矛盾已经解决，也不能认为人民日益增长的美好生活需要已经得到满足。

例如：

- 错：我国已经满足了人民“从有到优”的需求。
