# 毛中特 第四章 社会主义建设道路初步探索的理论成果

## 记忆部分

### 1. 调动一切积极因素为社会主义事业服务 [p112]

（1）《论十大关系》确定了探索社会主义建设道路的**原则和指导思想**，即**以苏为鉴，独立自主地探索适合中国情况的社会主义建设道路**。

（2）党探索中国社会主义建设道路的**良好开端的标志**：**《论十大关系》**。

（3）《论十大关系》确定了一个**基本方针**：**“把……一切积极因素，全部调动起来”，为社会主义建设服务**。（其他内容见附录2）

### 2. 正确认识和处理社会主义社会矛盾的思想 [p113]

（其他内容见附录2）

（1）社会主义社会的**基本矛盾**：**生产关系和生产力之间**的矛盾，**上层建筑和经济基础之间**的矛盾。（非对抗性的矛盾）

（2）社会主义社会基本矛盾运动的**特点**：**“又相适应又相矛盾”**。

（3）我国社会的**主要矛盾**。

**党的八大**正确分析了社会主义改造完成后**我国社会主要矛盾的变化**，指出了国内的主要矛盾已经不再是工人阶级和资产阶级的矛盾，而是**人民对于建立先进的工业国的要求同落后的农业国的现实之间的矛盾，是人民对于经济文化迅速发展的需要同当前经济文化不能满足人民需要的状况之间的矛盾**。

（4）社会主义社会**两类不同性质的矛盾**。

①两类不同性质的矛盾的存在是客观的，但在一定的条件下可以互相转化。

| 项目 | 敌我矛盾 | 人民内部矛盾 |
|---|---|---|
| **地位** | — | 居于主导地位 |
| **性质** | 对抗性的 | 非对抗性的 |
| **处理方法** | 专政 | 民主 |

②**解决人民内部矛盾的总方针**：用**民主的方法**。

| | |
|---|---|
| **政治思想领域** | “团结—批评—团结”的方针 |
| **物质利益、分配方面** | 统筹兼顾、适当安排的方针 |
| **人民群众和政府机关的矛盾** | 民主集中制原则 |
| **科学文化领域** | “百花齐放、百家争鸣”的方针 |
| **共产党和民主党派之间的矛盾** | “长期共存、互相监督”的方针 |
| **民族之间的矛盾** | 民族平等、团结互助的方针 |

③社会主义国家**政治生活的主题**：**关于正确处理人民内部矛盾的问题**。

这一论断的**根本着眼点**：**调动一切积极因素**，团结一切可以团结的力量，把全党的注意力转到社会主义建设上来。

### 3. 走中国工业化道路 [p114]

（1）为我国实现**工业化**提供了**根本政治前提**的是**中华人民共和国的成立**。

（2）**毛泽东在《关于正确处理人民内部矛盾的问题》中明确提出了**：**中国工业化道路的问题，主要是指重工业和轻工业、农业的发展关系问题，强调要走一条有别于苏联的中国工业化道路**。

（3）**关于工业化道路，毛泽东还提出了**：**以农业为基础，以工业为主导，以农轻重为序发展国民经济的总方针，以及一整套“两条腿走路”的工业化发展思路**。

（4）**《关于正确处理人民内部矛盾的问题》指出**：**中国工业化道路的问题，主要是指重工业和轻工业、农业的发展关系问题，强调要走一条有别于苏联的中国工业化道路**。毛泽东提出了以农业为基础，以工业为主导，以农轻重为序发展国民经济的总方针，以及一整套“两条腿走路”的工业化发展思路。

（5）走中国工业化道路的要求：

| | |
|---|---|
| **必须采取正确的经济建设方针** | 党的八大提出了既反保守又反冒进、坚持在综合平衡中稳步前进的方针；毛泽东多次阐述了统筹兼顾的方针等（其他内容见附录1） |
| **必须调整和完善所有制结构** | 提出了把资本主义经济作为社会主义经济的补充的思想；要注意发展手工业和农业多种经营的思想；“三个主体，三个补充”的设想等 |
| **必须积极探索适合我国情况的经济体制和运行机制** | 提出了发展商品生产、利用价值规律的思想；使社会主义经济既有计划性又有多样性和灵活性的主张，以及按经济办法管理经济的思想；要建立“适合于我国情况和人民需要的社会主义的市场”的思想；企业“两参一改三结合”；实行职工代表大会制等思想 |

### 4. 初步探索的部分其他理论成果 [p115]

| | |
|---|---|
| **关于社会主义发展阶段的思想** | 毛泽东提出社会主义又可能分为两个阶段，“第一个阶段是不发达的社会主义，第二个阶段是比较发达的社会主义。后一阶段可能比前一阶段需要更长的时间” |
| **关于经济建设的方针** | 中共八大提出了既反保守又反冒进、坚持在综合平衡中稳步前进的方针 |

| **关于“四个现代化”战略目标** | 周恩来在三届全国人大一次会议上正式宣布：把我国建设成为一个具有现代农业、现代工业、现代国防和现代科学技术的社会主义强国 |

### 5. 初步探索的意义 [p116]

第一，巩固和发展了我国的社会主义制度；第二，为开创中国特色社会主义提供了宝贵经验、理论准备、物质基础；第三，丰富了科学社会主义的理论和实践。

## 理解部分

### 1. **社会主义社会的基本矛盾及其性质** [p116]

社会主义社会的基本矛盾仍然是生产关系和生产力之间的矛盾，上层建筑和经济基础之间的矛盾，其性质是非对抗性的矛盾。由于社会主义社会的矛盾不是对抗性的矛盾，因此“它可以经过社会主义制度本身，不断地得到解决”。

> 命题思路：（1）注意该理论中包含着一个因果关系：因为社会主义的矛盾不是对抗性的，所以它才可以通过社会主义制度本身不断得到解决。命题过程中，可能会出现忽略原因，将结果夸大为普遍成立的情况，形成干扰选项。

例如：

- 错：一切社会的基本矛盾都可以通过其制度本身不断地得到解决。

### 2. **新中国成立初期的“方针”** [p116]

这一时期，不同的会议和文章中均有提出各种方针，比较容易混淆。常考的有：

1950年，中共七届三中全会提出的方针：不要四面出击。

1956年，《论十大关系》提出的方针：调动一切积极因素为社会主义事业服务。

1956年，中共八大提出的方针：既反保守又反冒进、坚持在综合平衡中稳步前进。

> 命题思路：（1）注意命题过程中，可能会将不同的方针混淆。

例如：

- 错：《论十大关系》提出了既反保守又反冒进、坚持在综合平衡中稳步前进的方针。
