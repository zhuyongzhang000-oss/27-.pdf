# 马原 第四章 唯物史观

## 记忆部分

### 1. 社会存在与社会意识 [p42]

（1）社会历史观的**基本问题**：**社会存在和社会意识的关系问题**。

（2）唯物史观与唯心史观的**根本分野**：**主张社会存在决定社会意识，还是社会意识决定社会存在**。

（3）唯心史观的**缺陷**：一是至多考察了人的活动的思想动机，而**没有进一步考究思想动机背后的物质动因和经济根源**；二是只看到了个人在历史上的作用，而**忽视了人民群众创造历史的决定作用**。

（4）**唯一科学的历史观**：**唯物史观**。

（5）社会存在。

| | | |
|---|---|---|
| **社会存在** | 自然地理环境 | 影响因素、必要条件 |
| **社会存在** | 人口因素 | 影响因素、必要条件 |
| **社会存在** | 物质生产方式 | 社会历史发展的决定力量 |

（6）社会意识。

| | | | |
|---|---|---|---|
| **社会意识** | 社会心理（低层次的、自发的，以感性认识为主） | — | — |
| **社会意识** | 社会意识形式（高层次的、自觉的，以理性认识为主） | 意识形态（与阶级立场有关） | 政治法律思想、道德、艺术、宗教、哲学等 |
| **社会意识** | 社会意识形式（高层次的、自觉的，以理性认识为主） | 非意识形态（与阶级立场无关） | 自然科学和语言学、形式逻辑等一部分社会科学 |

### 2. 社会基本矛盾1：生产力和生产关系 [p43]

（1）生产力的构成。

| | | | |
|---|---|---|---|
| **生产力** | 基本要素 | 生产资料 | 劳动资料（劳动手段） |
| **生产力** | 基本要素 | 生产资料 | 劳动对象 |
| **生产力** | 基本要素 | 劳动者 | — |
| **生产力** | 渗透性要素 | 科学技术 | — |

（2）劳动资料中**最重要**的是**生产工具**。

（3）既是生产力发展水平的**客观尺度**，也是**区分社会经济时代的客观依据**的是**生产工具**。

（4）生产力中**最活跃**的因素：**劳动者**。

（5）生产关系的构成。

| | |
|---|---|
| **生产关系** | 生产资料所有制关系（最基本的、决定性的） |
| **生产关系** | 生产中人与人的关系 |
| **生产关系** | 产品分配关系 |

（6）区分不同生产方式、**判定社会经济结构性质的客观依据**：**生产资料所有制关系**。

### 3. 社会基本矛盾2：经济基础和上层建筑 [p44]

（1）经济基础和上层建筑的构成。

| | | |
|---|---|---|
| **经济基础** | 指由社会一定发展阶段的生产力所决定的生产关系的总和 | 指由社会一定发展阶段的生产力所决定的生产关系的总和 |
| **上层建筑** | 政治上层建筑（政治法律制度及设施和政治组织） | 国家政治制度、立法司法制度和行政制度，以及国家政权机构、政党、军队、警察、法庭、监狱等政治组织形态和设施 |
| **上层建筑** | 观念上层建筑（意识形态） | 政治法律思想、道德、艺术、宗教、哲学等 |

（2）在整个上层建筑中，居**主导地位**的是**政治上层建筑**。

（3）**政治上层建筑的核心**是**国家政权**。

（4）**观念上层建筑的核心**是**政治法律思想**。

（5）**国家的实质**是**一个阶级统治另一个阶级的工具**。

### 4. 人类普遍交往与世界历史的形成发展 [p44]

（1）世界历史形成和发展的**基础**：**生产方式的发展变革**。

（2）世界历史的**基本特征**：**普遍交往**。

（3）**人类历史向世界历史转变的原因**：**资本主义生产方式出现和向世界扩张**。

### 5. 社会进步与社会形态更替 [p44]

（1）社会进步作为对社会前进发展的总概括，**主要表现在**：一是**社会形态从低级到高级的发展**。二是**同一社会形态内部的发展**。

（2）人的发展**最根本**的是**人的自由程度的提高**。

（3）唯物史观把人的发展从低级到高级依次概括为**三个阶段**，即**人的依赖关系**占统治地位的阶段、**以物的依赖关系为基础的人的独立性**的阶段、**自由个性**的阶段。

（4）人真正得到**自由而全面的发展**只有在**共产主义社会**。

（5）**社会形态**包括**经济形态、政治形态和意识形态**。

（6）人们的**历史选择性**包含三层意思：其一，**社会发展的必然性**造成了一定历史阶段社会发展的基本趋势，为人们的历史选择提供了基础、范围和可能性空间。其二，社会形态更替的过程也是一个**主观能动性与客观规律性相统一**的过程。其三，人们的历史选择性归根结底是**人民群众的选择性**。

### 6. 社会历史发展的动力 [p45]

（1）历史发展的**根本动力**：**社会基本矛盾**。

（2）既是社会基本矛盾运动中**最基本的动力因素**，也是人类社会发展和进步的**最终决定力量**的是**生产力**。

（3）**“一切历史冲突的根源”**：**生产力和生产关系的矛盾**。

（4）阶级社会发展的**直接动力**：**阶级斗争**。

（5）阶级斗争的**最高形式**：**革命**。

（6）**革命的实质**：**革命阶级推翻反动阶级的统治，用新的社会制度代替旧的社会制度**。

（7）实现社会形态更替的重要手段和**决定性环节**：**革命**。

### 7. 人民群众和个人的作用 [p45]

（1）唯物史观与唯心史观的**分水岭**：**历史创造者问题**。（是人民群众创造历史还是英雄创造历史）

（2）英雄史观（唯心史观）产生的**根源**：人们的认识**停留在历史现象的表面**，把活跃在历史前台的少数英雄人物的作用尤其是他们的意识作用加以夸大并绝对化，是其认识根源；**社会生产力水平较低**，社会的政治统治和精神生活被少数人垄断，是其社会历史根源；**剥削阶级为维护本阶级的利益**宣扬唯心史观，是其阶级根源。

## 理解部分

### 1. **唯物史观中的“决定性因素”** [p46]

| 项目 | “决定性”因素 | 具体表述 | 题目中的限定条件 |
|---|---|---|---|
| **高权限的“决定”** | 物质生产方式 | 物质生产方式是社会历史发展的决定力量 | 人类社会历史 |
| **高权限的“决定”** | 生产力 | 生产力是人类社会发展和进步的最终决定力量 | 人类社会历史 |
| **高权限的“决定”** | 社会基本矛盾 | 社会基本矛盾是历史发展的根本动力 | 人类社会历史 |
| **高权限的“决定”** | 人民群众 | 人民群众是历史的创造者，决定历史的总进程和总方向 | 人类社会历史 |
| **低权限的“决定”** | 脑力劳动 | 在现代生产中，脑力劳动者的质量和数量日益具有决定性的意义 | 现代生产 |
| **低权限的“决定”** | 生产资料所有制 | 生产资料所有制关系是生产关系中最基本的、决定性的关系 | 生产关系 |
| **低权限的“决定”** | 科学技术 | 在现代，科学技术日益成为生产发展的决定性因素 | 现代生产劳动 |
| **低权限的“决定”** | 历史人物 | 历史人物有时会对历史事件的进程和结局产生决定性的影响 | 具体历史事件 |

> 命题思路：（1）注意错误选项会把低权限的“决定”曲解为高权限的“决定”。

例如：

- 错：科学技术是人类社会历史发展的决定性因素。

### 2. **唯物史观中的各种“辩证关系”** [p47]

| | | |
|---|---|---|
| **社会存在与社会意识** | 社会存在决定社会意识 | ①社会存在是社会意识内容的客观来源，社会意识是社会物质生活过程及其条件的主观反映。<br>②社会意识是人们进行社会物质交往的产物。<br>③随着社会存在的发展，社会意识也相应地或迟或早地变化和发展 |
| **社会存在与社会意识** | 社会意识具有相对独立性 | ①社会意识与社会存在发展具有不完全同步性和不平衡性。<br>②社会意识内部各种形式之间存在相互影响且各自具有历史继承性。<br>③社会意识对社会存在具有能动的反作用，这是社会意识相对独立性的突出表现 |
| **生产力与生产关系** | 生产力决定生产关系 | ①有什么样的生产力，就会产生什么样的生产关系。<br>②当一种生产关系还能适应生产力发展时，它是不会灭亡的。<br>③当生产力发展到一定阶段，生产关系不适合生产力发展时，必然引起生产关系的变革 |
| **生产力与生产关系** | 生产关系反作用于生产力 | ①当生产关系适合生产力发展的客观要求时，对生产力的发展起推动作用。<br>②当生产关系不适合生产力发展的客观要求时，就会阻碍生产力的发展 |
| **经济基础与上层建筑** | 经济基础决定上层建筑 | 经济基础的需要决定上层建筑的产生、性质和变化 |
| **经济基础与上层建筑** | 上层建筑对经济基础具有反作用 | 上层建筑反作用的性质，取决于它所服务的经济基础的性质，归根到底取决于它是否有利于生产力的发展 |

> 命题思路：（1）注意错误选项会颠倒上述关系。这些辩证关系均符合“A决定B，B反作用于A（B具有相对独立性）”的模式。

例如：

- 错：社会心态的差异性决定社会生活的多样性。

> （2）注意错误选项会把“或迟或早”曲解为“亦步亦趋”。社会意识与社会存在发展具有不完全同步性和不平衡性，社会意识不会随着社会存在的变化而立刻变化。

例如：

- 错：随着社会存在的发展，社会意识会立刻发生变化。
- 错：法治意识只能落后于新技术发展。

> （3）注意错误选项会脱离“适配性”，孤立地谈生产关系的优越性。判断一种生产关系是否优越，在于这种生产关系对生产力是适合还是不适合，是促进生产力发展还是阻碍生产力发展。若在生产力尚未达到一定高度的情况下强行套用先进的生产关系，其结果也会是阻碍生产力的发展，无异于“揠苗助长”。

例如：

- 错：越是先进的生产关系，就越能促进生产力的发展。

> （4）注意错误选项会从“适配性”的角度去定义上层建筑的性质。上层建筑的性质是先进的还是落后的，不取决于上层建筑是否适合经济基础或是否愿意服务于经济基础，而是取决于它所服务的经济基础的性质。上层建筑若服务于落后的经济基础，该上层建筑就是落后的。

例如：

- 错：上层建筑的性质取决于其是否能够为经济基础服务。

> （5）注意凡是“反作用”都分为积极的或消极的，错误选项会把反作用说成“总是积极的”或“总是消极的”。

例如：

- 错：社会意识总是对社会存在起着积极的反作用。

### 3. **社会形态更替的特点** [p49]

| | | | |
|---|---|---|---|
| **统一性和多样性** | 从纵向看 | 统一性 | 社会形态运动由低级到高级、由简单到复杂的过程，人类的总体历史过程表现为五种社会形态的依次更替 |
| **统一性和多样性** | 从纵向看 | 多样性 | 不同的民族可以超越一种或几种社会形态而跳跃式地向前发展 |
| **统一性和多样性** | 从横向看 | 统一性 | 同类社会形态有共同的本质 |
| **统一性和多样性** | 从横向看 | 多样性 | 每一种社会形态在不同的民族那里都有自己的特殊表现形式 |
| **必然性与选择性** | 客观必然性 | 客观必然性 | 社会形态发展的基本趋势是确定不移的 |
| **必然性与选择性** | 历史选择性 | 历史选择性 | 必然性为人们的历史选择提供了基础、范围和可能性空间，归根结底是人民群众的选择性 |
| **前进性与曲折性** | 前进性 | 前进性 | 总趋势是前进的 |
| **前进性与曲折性** | 曲折性 | 曲折性 | 社会前进过程中所出现的反复、停滞和倒退现象 |

> 命题思路：（1）注意错误选项会割裂社会形态更替的统一性和多样性。社会形态更替的多样性并不否定其统一性。

例如：

- 错：世界发展的一般过程拒斥个别国家发展过程的特殊性。
- 对：一些国家社会发展的特殊形式不能否定历史发展的普遍规律。

### 4. **唯物史观考察历史创造者的原则** [p50]

| | |
|---|---|
| **立足于现实的人及其本质来把握历史的创造者** | “人的本质不是单个人所固有的抽象物，在其现实性上，它是一切社会关系的总和。”人的本质属性是社会属性，而不是自然属性；人的本质属性表现在各种社会关系中；人的本质是变化发展的，而不是永恒不变的 |
| **立足于整体的社会历史过程来探究谁是历史的创造者** | 历史是无数个追求着自己目的的人的活动的合力 |
| **从社会历史发展的必然性入手来考察和说明谁是历史的创造者** | 只有代表推动和促进社会历史向前发展的力量的人才属于历史的创造者 |
| **从人与历史关系的不同层次上考察谁是历史的创造者** | 人与历史的关系具有人类与历史、群体与历史、个体与历史三层关系 |

> 命题思路：（1）注意错误选项会将人的本质曲解为个人的、自然的和永恒的。人的本质属性是社会属性，我们只能在各种不断变化的社会关系和社会实践中去定义人的本质，而无法在单个人身上找到“人是什么”的固定答案。现实的人及其活动是社会历史产生的起点和前提，现实的人是从事实际活动的人，是被各种社会属性规定的人，而非脱离社会孤立存在的人（抽象的人）。要特别注意选项中的“单个人固有的抽象物”“自然属性”“永恒不变的人性”等关键词。

各类关于“人”的表述：

| | |
|---|---|
| **正确说法** | 现实的人、具体的人、历史的人 |
| **错误说法** | 抽象的人、超阶级的人、永恒不变的人性 |

例如：

- 错：抽象的人及其活动是社会历史产生的起点和前提。

> （2）注意错误选项会夸大个人的作用。尽管每个人的意志与行动看似各不相同，但历史是无数个追求着自己目的的人的活动的合力，只有这种合力才能推动历史的前进。就每个人而言，他在一定意义上“创造”了自己的“历史”，但不能说他创造了整个社会历史。

例如：

- 对：历史是无数个人相互作用的合力的结果。
- 错：人人都是历史的创造者。

### 5. **人民群众和历史人物** [p51]

| 项目 | 人民群众 | 历史人物 |
|---|---|---|
| **含义** | 从质上说，人民群众是指一切对社会历史发展起推动作用的人。<br>从量上说，人民群众是指社会人口中的绝大多数。<br>人民群众中最稳定的主体部分始终是从事物质资料生产的劳动群众（及其知识分子） | 历史人物是一定历史事件的主要倡导者、组织领导者或思想理论、科学文化的重要代表人物。<br>杰出人物是历史人物中对推动历史发展作出重要贡献或起重要作用的人 |
| **作用** | 人民群众是社会历史实践的主体，是历史的创造者 | ①任何历史人物的出现都体现了必然性与偶然性的统一。<br>②历史人物对历史的发展起加速或延缓作用。<br>③历史人物不能决定和改变历史发展的总进程和总方向 |

> 命题思路：（1）注意错误选项会将劳动群众作为人民群众的唯一内容。在不同的历史时期，人民群众有着不同的内容，包含着不同的阶级、阶层和集团，所以人民群众的内容是多样的。“是否对历史起推动作用”是判定人民群众的标准，即便是剥削阶级，也曾经在历史上起过积极的推动作用，也曾属于人民群众的范畴。

例如：

- 错：人民群众在任何历史时期都不包括剥削阶级。

> （2）注意错误选项会曲解历史人物的作用。唯物史观中最高频的错误选项之一便是夸大历史人物（个人）的作用。此外，根据对历史的作用和对人民群众的顺应程度，历史人物可分为促进历史发展的杰出人物和阻碍历史发展的反动人物。

例如：

- 对：历史人物会因其智慧、性格等因素对社会进程发生影响。
- 错：杰出人物与人民群众的历史作用是同等重要的。
- 错：杰出人物能够改变历史发展的基本方向。
- 错：历史人物对历史的发展始终起积极作用。

> （3）注意错误选项会背离唯物史观的原理，对无产阶级领袖进行错误评价。无产阶级领袖不同于以往历史上的杰出人物，他们所代表的是历史上最革命、最先进的阶级，在革命和建设中发挥了重大作用。但无产阶级领袖也属于历史人物的范畴，也不能创造或决定历史，应当正确评价无产阶级领袖的历史作用。

例如：

- 错：无产阶级领袖能够创造人类的历史。
