### 2. 社会主义道德 [p281]

（1）与以往社会的道德形态相比，社会主义道德具有**显著的先进性特征**。

| **先进性特征** | **具体解释** |
|---|---|
| 社会主义道德是社会主义经济基础的反映 | 社会主义道德的经济基础是公有制，所以，广大人民在道德上实现了由被动到主动的转变 |
| 社会主义道德是对人类优秀道德资源的批判继承和创新发展 | 与中华传统美德相承接；与中国革命道德相延续；对人类优秀道德成果的吸收和借鉴 |
| 社会主义道德克服了以往阶级社会道德的片面性和局限性 | 坚持以为人民服务为核心；坚持以集体主义为原则 |

（2）坚持以为人民服务为核心。

①道德的**核心问题**：**为什么人服务。**这决定并体现着道德建设的根本性质和发展方向，规定并制约着道德领域中的所有道德现象。②社会主义道德的**核心**：**为人民服务。**这是社会主义道德区别和优越于其他社会形态道德的显著标志。③为人民服务的意义：是坚持历史唯物主义的必然要求，是中国共产党践行的根本宗旨，是社会主义道德观的集中体现，是全体中国人民共同遵循的道德要求。

（3）坚持以集体主义为原则。

①调节国家利益、社会整体利益和个人利益关系的**基本原则**：**集体主义。**

|  |  |
|---|---|
| **基本原则** | 集体主义强调国家利益、社会整体利益和个人利益的辩证统一 |
| **基本原则** | 集体主义强调国家利益、社会整体利益高于个人利益 |
| **基本原则** | 集体主义重视和保障个人的正当利益 |

②集体主义的层次性。

|  |  |
|---|---|
| **无私奉献、一心为公** | 最高层次；是优秀共产党员、先进分子应努力达到的道德目标 |
| **先公后私、先人后己** | 具有较高社会主义道德觉悟的人能够达到的要求 |
| **顾全大局、遵纪守法、热爱祖国、诚实劳动** | 对公民最基本的道德要求 |

### 3. 中华传统美德 [p282]

## 理解部分

### 1. **道德的本质和作用** [p285]

（1）道德的本质：道德是一种特殊的社会意识形态，它是以善恶为评价方式，主要依靠社会舆论、传统习俗和内心信念来发挥作用的行为规范的总和。道德是反映社会经济关系的特殊意识形态；是社会利益关系的特殊调节方式；是一种实践精神。

（2）道德的作用：①作为维系社会稳定、促进国家发展的重要因素，巩固特定社会的经济基础和上层建筑。②作为激励人们改造客观世界和主观世界的一种精神力量，是提高人的精神境界、促进人的自我完善、推动人的全面发展的内在动力。③道德发挥作用的性质与社会发展的不同历史阶段相联系，由道德所反映的经济基础、代表的阶级利益所决定。

> 命题思路：（1）注意“道德是反映社会经济关系的特殊意识形态”，所以它具有和意识形态一样的特征和属性。

例如：

- 对：道德的产生、发展和变化，归根到底源于社会经济关系。
- 对：道德一经产生，便有相对独立性。

> （2）注意道德作为一种社会意识，在阶级社会里总是反映着一定阶级的利益，因而不可避免地具有阶级性。同时，不同阶级之间的道德或多或少有一些共同之处，反映着道德的普遍性。

例如：

- 错：不同阶级之间的道德没有共同之处。
- 错：道德具有普遍性，不同阶级之间的道德完全一致。

### 2. **社会主义道德坚持以为人民服务为核心** [p286]

为人民服务作为社会主义道德的核心，是社会主义道德区别和优越于其他社会形态道德的显著标志。原因在于：

（1）为人民服务是社会主义道德的本质要求。①是社会主义经济基础和人际关系的客观要求；②是社会主义市场经济健康发展的要求。

（2）为人民服务是先进性要求和广泛性要求的统一。

> 命题思路：（1）注意理解“先进性要求”和“广泛性要求”。为人民服务既伟大又平凡，这个要求不仅适用于党员干部，也要推广到全体人民。

例如：

- 错：为人民服务仅仅是对优秀共产党员和先进分子的要求。

### 3. **中华传统美德的基本精神** [p287]

|  |  |
|---|---|
| **重视整体利益，强调责任奉献** | “以公灭私，民其允怀”“国而忘家，公而忘私”“苟利国家生死以，岂因祸福避趋之”“夙夜在公” |
| **推崇仁爱原则，注重以和为贵** | “己欲立而立人，己欲达而达人”“仁者自爱”“兼相爱，交相利”“亲亲而仁民，仁民而爱物” |
| **注重人伦关系，重视道德义务** | “父子有亲、君臣有义、夫妇有别、长幼有序、朋友有信”“仁、义、礼、智、信”“忠、孝、节、义” |
| **追求精神境界，向往理想人格** | 孔颜之乐、“大丈夫”人格、“先天下之忧而忧，后天下之乐而乐” |
| **强调道德修养，注重道德践履** | “修身”“修己”“克己”“慎独”“善养吾浩然之气”“见贤思齐焉，见不贤而内自省也”“察色修身”“以身戴行” |

> 命题思路：（1）注意古诗名句与中华传统美德基本精神的对应。

例如：

- 错：从《诗经》中的“夙夜在公”到清代林则徐的“苟利国家生死以，岂因祸福避趋之”，贯穿其中的中华传统美德是“注重人伦关系，重视道德义务”。

### 4. **传统道德** [p287]

传统道德是一个矛盾体，具有鲜明的两重性。属于精华的部分，表现出积极、革新、进步的一面；属于糟粕的部分，则表现出消极、保守、落后的一面。中华传统美德作为中国传统道德的精华部分，为今天的道德建设提供了丰富的资源。

> 命题思路：（1）注意区分传统道德和传统美德。对待传统道德应该取其精华、去其糟粕；对待传统美德应该创造性转化和创新性发展。二者都不能直接拿来用。

例如：

- 错：当今中国，必须构建以中华传统美德为主体的道德体系。

### 5. **道德修养的方法** [p288]

|  |  |
|---|---|
| **学思并重** | 虚心学习、积极思索、辨别善恶、学善戒恶 |
| **省察克治** | 通过反省检验以发现自己思想和行为中的不良倾向，并及时抑制和克服 |
| **慎独自律** | 在无人知晓的情况下，对个人内心深处比较隐蔽的意识、情绪进行管理和自律 |
| **知行合一** | 把提高道德认识与躬行道德实践统一起来 |
| **积善成德** | 通过积累善行或美德，使之巩固强化 |

> 命题思路：（1）注意理解五种道德修养方法的含义，题目可能会和故事、名言警句相结合，选项出现错配。

例如：

- 错：“吾日三省吾身”属于中国传统道德修养方法中的积善成德。
