# 史纲 第二章 不同社会力量对国家出路的早期探索

## 记忆部分

**（一）农民阶级的探索**

### 1. 太平天国农民战争的爆发和意义 [p200]

（1）爆发原因：一方面，清政府加重了赋税的征收科派，农民的负担更为沉重；另一方面，中国的农业和家庭手工业相结合的自然经济逐渐解体。

（2）战争的性质：太平军所进行的战争，是一次反对清政府腐朽统治和地主阶级压迫、剥削的正义战争。

（3）战争的历史意义：

第一，太平天国农民战争沉重打击了封建统治阶级，强烈撼动了清政府的统治根基。

第二，太平天国农民战争是中国旧式农民战争的最高峰。

第三，太平天国农民战争冲击了孔子和儒家经典的正统权威。

第四，太平天国农民战争有力地打击了外国侵略势力。

第五，在19世纪中叶的亚洲民族解放运动中，太平天国农民战争是时间最久、规模最大、影响最深的一次。

### 2. 太平天国农民战争的失败和教训 [p201]

（1）太平天国由盛转衰的分水岭：太平天国内部自相残杀的天京事变。

（2）战争失败的原因：

第一，农民阶级不是新的生产力和生产关系的代表，无法克服小生产者所固有的阶级局限性，缺乏科学思想理论的指导，没有先进阶级的领导，因而无法从根本上提出完整的、正确的政治纲领和社会改革方案。（根本原因）

第二，太平天国后期无法制止和克服领导集团自身腐败现象的滋生。

第三，太平天国军事战略上出现了重大失误。

第四，拜上帝教教义给农民战争带来了危害。

第五，太平天国未能正确地对待儒学。

第六，太平天国的领袖们对于西方资本主义侵略者还缺乏理性的认识。

（3）战争失败的教训：在半殖民地半封建的中国，农民具有伟大的革命潜力，但它自身不能担负起领导反帝反封建斗争取得胜利的重任。

**（二）地主阶级的探索**

### 1. 洋务事业的兴办 [p202]

（1）兴起的原因：第一，为了购买和制造洋枪洋炮以镇压农民起义；第二，借此加强海防、边防，并乘机发展本集团的政治、经济和军事实力。

（2）**指导思想**：**“中学为体，西学为用。”**“中体西用”就是以中国封建伦理纲常所维护的统治秩序为主体，用西方的近代工业和技术为辅助，并以前者来支配后者。

**（三）资产阶级维新派的探索**

### 1. 戊戌维新运动的开展 [p203]

（1）戊戌维新运动兴起的原因：第一，中国民族资本主义有了初步发展；第二，在内忧外患的冲击和中西文化的碰撞过程中，人们逐步形成了一个共识，要救国，只有维新，要维新，只有学外国。

（2）戊戌维新运动的宣传行动：第一，向皇帝上书；第二，著书立说；第三，介绍外国变法的经验教训；第四，办学会；第五，设学堂；第六，办报纸。

（3）维新派进行改良的方式：将重点放在争取光绪皇帝及其周围的帝党官员的支持上，希望通过他们自上而下地实行变法主张。

（4）戊戌维新运动的**进步性**：“百日维新”期间颁布的各项政令大多是接受了维新派的建议而制定的，旨在**使资产阶级享受一定程度的政治权利，促进资本主义工商业的发展**。

（5）戊戌维新运动的**局限性**：**其政令和措施并未触及封建制度的根本，所要推行的是一种十分温和的不彻底的改革方案**。

（6）戊戌维新运动的结果：除京师大学堂（北京大学的前身）被保留下来以外，其余新政措施大都被废除。

### 2. 维新派和守旧派的论战 [p204]

（1）论战的主要内容：首先，要不要变法；其次，要不要兴民权、设议院，实行君主立宪；最后，要不要废八股、改科举和兴西学。

（2）对论战的**评价**：维新派与守旧派的这场论战，**实质上是资产阶级思想与封建主义思想在中国的第一次正面交锋。论战进一步开阔了新型知识分子的眼界，解放了人们长期受到束缚的思想。通过论战，西方资产阶级社会政治学说在中国得到进一步的传播**。

### 3. 戊戌维新运动的意义、失败的原因和教训 [p204]

（1）戊戌维新运动的意义：首先，戊戌维新运动**是一次爱国救亡运动**；其次，戊戌维新运动**是一场资产阶级性质的政治改良运动**；最后，戊戌维新运动更**是一场思想启蒙运动**。京师大学堂的创设，成为中国近代国立高等教育的发端。

（2）戊戌维新运动失败的**原因**：**主要是维新派自身的局限（根本原因）和以慈禧太后为首的强大的守旧势力的反对。第一，民族资产阶级力量弱小。第二，维新派的局限性。表现：一是不敢否定封建主义；二是对帝国主义抱有幻想；三是惧怕人民群众**。

（3）戊戌维新运动失败的教训：在半殖民地半封建的旧中国，企图通过统治阶级自上而下的改良实现国家的独立、民主、富强是根本行不通的，必须用革命的手段，推翻帝国主义、封建主义联合统治的半殖民地半封建的社会制度。

## 理解部分

### 1. **《天朝田亩制度》和《资政新篇》** [p205]

| | | |
|---|---|---|
| **《天朝田亩制度》** | **内容** | **《天朝田亩制度》是最能体现太平天国社会理想和这次农民起义特色的纲领性文件**。它根据“凡天下田，天下人同耕”的原则确立了平均分配土地的方案。《天朝田亩制度》实际上是由起义农民提出的一个以解决土地问题为中心的比较完整的社会改革方案 |
| **《天朝田亩制度》** | **进步性** | **从根本上否定了封建社会的基础即封建地主的土地所有制** |
| **《天朝田亩制度》** | **局限性** | ①并没有超出农民小生产者的狭隘眼界。<br>②具有不切实际的空想性质。<br>③并未付诸实施 |
| **《资政新篇》** | **进步性** | 是一个具有资本主义色彩的方案 |
| **《资政新篇》** | **局限性** | 限于当时的历史条件，未能付诸实施 |

> 命题思路：（1）注意太平天国“平分土地”的土地政策仅仅是“明确提出主张”，而不是“事实上彻底完成”。

例如：

- 错：太平天国农民战争没有主张废除封建土地剥削制度。
- 错：太平天国农民战争没有否定封建土地剥削制度。
- 错：太平天国农民战争彻底废除了中国的封建土地剥削制度。

### 2. **“百日维新”的性质** [p205]

（1）“百日维新”期间颁布的各项政令大多是接受了维新派的建议而制定的，旨在开放一定程度的言论、出版、结社自由，使资产阶级享受一定程度的政治权利，促进资本主义工商业的发展。因此，戊戌维新运动是一场资产阶级性质的改良运动。

（2）在光绪皇帝发布的新政诏令中，并没有采纳维新派多次提出的开国会、定宪法等政治主张。这些政令和措施并未触及封建制度的根本，所要推行的是一种十分温和的不彻底的改革方案。

（3）这些主张充分暴露了维新派的诸多局限性：政治上不敢根本否定封建君主制度，只是幻想依靠光绪皇帝，通过和平、合法的手段，实现自上而下的改良，让资产阶级和开明士绅的代表参加政权，逐步实现君主立宪；经济上虽然要求发展民族资本主义，却未触及封建主义的经济基础——封建土地所有制；思想上虽然提倡学习西学，却仍打着孔子的旗号，借古代圣贤之名“托古改制”。

> 命题思路：（1）注意戊戌维新运动对待传统儒家思想采取了“托古改制”的态度，而不是“彻底否定”。

例如：

- 错：戊戌维新运动提倡全面学习“西学”，彻底否定“中学”。
- 错：维新派尖锐批判儒家思想，倡导摒弃传统礼教。

> （2）注意戊戌维新运动对待封建制度采取了“温和改良”的态度，而不是“彻底否定”。

例如：

- 错：戊戌维新运动的改革措施触及了封建制度的根本。
- 错：戊戌维新运动废除了君主专制制度。
- 错：戊戌维新运动带有彻底性和不妥协性。
- 错：戊戌维新运动是一场彻底反帝反封建的资产阶级民主革命。
